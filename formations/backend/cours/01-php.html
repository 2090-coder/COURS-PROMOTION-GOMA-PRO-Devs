Installer PHP et préparer son environnement

Avant de programmer, il faut comprendre ce qu'est PHP, installer l'outil et vérifier qu'il fonctionne. PHP peut servir à créer des sites et applications côté serveur. Pour une application Web, PHP travaille avec un serveur et un navigateur.

1. Ce qu'il faut installer

  • Un ordinateur Windows.
  • PHP.
  • Un éditeur de code comme VS Code.
  • Un navigateur Web.
  • Plus tard : MySQL pour les bases de données.

La documentation officielle de PHP fournit les instructions d'installation Windows et les versions officielles. Pour débuter, nous utiliserons PHP en ligne de commande et son serveur local intégré.

2. Vérifier Windows

Ouvrez PowerShell ou l'invite de commandes et testez :

php -v

Si Windows répond que la commande n'existe pas, PHP n'est pas encore installé ou son dossier n'est pas dans PATH.

3. Installer PHP

  1. Télécharger une distribution officielle adaptée à Windows 64 bits.
  2. Décompresser PHP dans un dossier simple, par exemple C:\php.
  3. Vérifier que php.exe se trouve dans ce dossier.
  4. Ajouter C:\php à la variable d'environnement Path.
  5. Fermer puis rouvrir PowerShell.
  6. Relancer php -v.

4. Créer le premier projet

mkdir C:\cours-php
cd C:\cours-php
notepad index.php

Dans index.php :

<?php
echo "Bonjour GOMA PRO Devs !";

5. Lancer PHP

cd C:\cours-php
php -S localhost:8000

Le terminal doit rester ouvert. Dans le navigateur, ouvrez http://localhost:8000. Le navigateur affiche le résultat produit par PHP.

6. Vérifier la configuration

Créez temporairement un fichier info.php :

<?php
phpinfo();

Ouvrez http://localhost:8000/info.php. Après le test, supprimez ce fichier d'information.

TP

  1. Installer PHP et faire fonctionner php -v.
  2. Créer index.php et afficher votre nom.
  3. Lancer le serveur local.
  4. Afficher le résultat dans le navigateur.
  5. Écrire dans votre cahier les étapes d'installation.
