PHP : programmer côté serveur

PHP s'exécute sur le serveur et peut générer du HTML, traiter des formulaires et communiquer avec une base de données.

Premier script

<?php
$nom = "Étudiant";
$age = 18;
echo "Bonjour $nom, tu as $age ans.";

Conditions et fonctions

function estAdmis(float $note): bool {
    return $note >= 10;
}

if (estAdmis(14)) {
    echo "Admis";
}

Formulaire

Les données reçues doivent être validées côté serveur. Ne considérez jamais les données du navigateur comme fiables.

TP

  1. Créer une page PHP qui affiche une liste d'étudiants.
  2. Créer un formulaire de contact et valider ses champs.
  3. Écrire des fonctions réutilisables.
