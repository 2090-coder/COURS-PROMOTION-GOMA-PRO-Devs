WEB BACKEND · CHAPITRE 01

Installer PHP avec XAMPP et lancer son premier programme

Objectif : partir d'un ordinateur Windows sans environnement PHP et arriver à une première page PHP affichée dans le navigateur.

1. Qu'est-ce que PHP ?

PHP est un langage exécuté côté serveur. Le serveur traite le fichier PHP puis renvoie au navigateur le résultat qu'il doit afficher.

2. Pourquoi XAMPP ?

XAMPP regroupe notamment Apache, PHP, MariaDB et des outils utiles pour créer un environnement local. Cela permet de travailler sur son ordinateur avant la mise en ligne.

3. Installation de XAMPP

  1. Télécharger l'installateur XAMPP depuis sa source officielle.
  2. Lancer l'installateur.
  3. Conserver Apache et PHP ; installer MariaDB si le parcours base de données est prévu.
  4. Choisir un dossier simple, par exemple C:\xampp.
  5. Terminer l'installation.

4. Lancer XAMPP

  1. Ouvrir XAMPP Control Panel.
  2. Cliquer sur Start à côté d'Apache.
  3. Cliquer sur Start à côté de MySQL lorsque nous commencerons les bases de données.
  4. Si Apache ne démarre pas, lire le message d'erreur au lieu de modifier les ports au hasard.

5. Premier dossier PHP

Dans XAMPP, le dossier web local est généralement C:\xampp\htdocs.

C:\xampp\htdocs\goma-backend\

Créer un fichier index.php.

6. Premier code PHP

<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <title>Mon premier PHP</title>
</head>
<body>
  <h1>GOMA PRO Devs</h1>
  <?php
    echo "Bonjour, je programme en PHP !";
  ?>
</body>
</html>

7. Voir le résultat

Avec Apache démarré, ouvrir :

http://localhost/goma-backend/

Ne pas double-cliquer sur le fichier PHP pour apprendre le fonctionnement serveur : le but est que PHP soit interprété par le serveur.

8. Vérifier PHP

Créer temporairement info.php :

<?php
phpinfo();

Ouvrir http://localhost/goma-backend/info.php. Supprimer ce fichier après le test sur un environnement destiné à être partagé.

9. Alternative avec PHP seul

PHP peut aussi être utilisé depuis le terminal si PHP est installé et disponible dans PATH :

php -v
php -S localhost:8000

Cette méthode est utile pour apprendre, mais XAMPP est pratique pour le parcours PHP + base de données.

10. Les premières règles

  • Les instructions PHP sont généralement entre <?php et ?>.
  • echo produit une sortie.
  • Une instruction se termine souvent par ;.
  • PHP peut être mélangé avec HTML.

TP

  1. Installer XAMPP.
  2. Démarrer Apache.
  3. Créer goma-backend/index.php.
  4. Afficher votre prénom avec echo.
  5. Ajouter une deuxième phrase.
  6. Afficher la page dans le navigateur.
