WEB BACKEND · CHAPITRE 03

Voir le résultat et mélanger PHP avec HTML

PHP travaille côté serveur. Le serveur exécute le code PHP puis envoie au navigateur le résultat HTML. Le navigateur affiche ensuite cette page.

1. PHP dans une page HTML

<!doctype html>
<html lang="fr">
<body>
    <h1>Mon site</h1>
    <p>Bonjour <?php echo "Aline"; ?></p>
</body>
</html>

2. Afficher des données

<?php
$prenom = "Jean";
?>
<h1>Bonjour <?= htmlspecialchars($prenom) ?></h1>

Lorsqu'une donnée vient d'un utilisateur, on apprend à l'afficher avec un échappement adapté au contexte afin d'éviter d'injecter du HTML non désiré.

3. Liens entre les pages

<a href="contact.php">Contact</a>
<a href="profil.php?id=15">Voir le profil</a>

4. Réutiliser le HTML

<?php include "header.php"; ?>
<main>Contenu de la page</main>
<?php include "footer.php"; ?>

5. Comprendre le chemin du résultat

  1. Le navigateur demande une URL.
  2. Le serveur reçoit la demande.
  3. PHP exécute le script.
  4. PHP produit du HTML.
  5. Le serveur renvoie la réponse.
  6. Le navigateur affiche la page.

TP

  1. Créer index.php avec un titre HTML.
  2. Afficher dynamiquement un prénom et une liste.
  3. Créer header.php et footer.php.
  4. Relier deux pages avec des liens.

Questions
