PHP + HTML : construire des pages dynamiques

Nous allons comprendre ce que fait le serveur, comment PHP produit HTML et comment organiser plusieurs pages.

1. Le trajet d'une page

  1. Le navigateur demande une URL.
  2. Apache reçoit la demande.
  3. PHP exécute le code serveur.
  4. Le serveur renvoie le résultat HTML.
  5. Le navigateur affiche la page.

2. PHP dans HTML

<h1>Mon profil</h1>
<?php
$nom = 'Aline';
?>
<p>Nom : <?= htmlspecialchars($nom) ?></p>

3. Affichage conditionnel

<?php if ($connecte): ?>
  <p>Bienvenue dans votre espace.</p>
<?php else: ?>
  <p>Veuillez vous connecter.</p>
<?php endif; ?>

4. Liens entre pages

<a href="contact.php">Contact</a>
<a href="login.php">Connexion</a>

5. Réutiliser une partie HTML

<?php include 'header.php'; ?>
<main>
  <h1>Accueil</h1>
</main>
<?php include 'footer.php'; ?>

Cette technique évite de recopier la même navigation et le même pied de page dans toutes les pages.

6. Données dans une liste

<?php
$formations = ['Frontend', 'Backend', 'Arduino'];
?>
<ul>
<?php foreach ($formations as $formation): ?>
  <li><?= htmlspecialchars($formation) ?></li>
<?php endforeach; ?>
</ul>
