SQL et bases de données

SQL permet de définir, rechercher, modifier et relier les données d'une base relationnelle.

Créer une table

CREATE TABLE etudiants (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nom VARCHAR(100) NOT NULL,
  email VARCHAR(150) UNIQUE NOT NULL,
  note DECIMAL(4,2)
);

Requêtes essentielles

SELECT id, nom, note
FROM etudiants
WHERE note >= 10
ORDER BY note DESC;

INSERT INTO etudiants (nom, email, note)
VALUES ('Aline', 'aline@example.test', 14);

Relations

Une relation permet de relier des tables par des clés. Les jointures permettent ensuite de récupérer les informations associées.

SELECT e.nom, f.nom AS formation
FROM inscriptions i
JOIN etudiants e ON e.id = i.etudiant_id
JOIN formations f ON f.id = i.formation_id;
