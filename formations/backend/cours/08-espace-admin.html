Espace utilisateur, rôles et administration

Une fois la connexion créée, il faut empêcher un visiteur non connecté d'entrer dans certaines pages et distinguer les droits d'un utilisateur normal et d'un administrateur.

1. Vérifier la connexion

session_start();

if (!isset($_SESSION['user_id'])) {
    header('Location: login.php');
    exit;
}

2. Vérifier un rôle

if (($_SESSION['role'] ?? '') !== 'admin') {
    http_response_code(403);
    exit('Accès interdit');
}

Une autorisation doit être contrôlée côté serveur pour chaque opération sensible. Cacher un bouton dans HTML ne suffit pas.

3. CRUD d'administration

  • Créer un utilisateur ou une formation.
  • Afficher les données.
  • Modifier une donnée.
  • Supprimer une donnée après confirmation.

4. Validation

Avant chaque écriture, vérifier les types, longueurs, formats, droits et contraintes de la base. Les erreurs doivent être gérées sans révéler de secrets techniques à l'utilisateur.
