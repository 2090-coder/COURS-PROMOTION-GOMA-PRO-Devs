WEB BACKEND · CHAPITRE 08

Espace utilisateur, rôles et administration

Après l'authentification, nous séparons clairement l'identité d'un utilisateur de ses permissions.

1. Authentification et autorisation

Authentification : vérifier qui est connecté. Autorisation : vérifier ce que cette personne a le droit de faire.

2. Protéger une page

session_start();
if (!isset($_SESSION['user_id'])) {
    header('Location: login.php');
    exit;
}

3. Vérifier le rôle

if (($_SESSION['role'] ?? '') !== 'admin') {
    http_response_code(403);
    exit('Accès interdit');
}

Cacher un bouton dans HTML ne protège pas une opération. La permission doit être contrôlée côté serveur.

4. Dashboard utilisateur

<h1>Mon espace</h1>
<p>Utilisateur connecté : <?= htmlspecialchars($nom) ?></p>
<a href="logout.php">Déconnexion</a>

5. Administration

Un espace admin peut gérer les formations ou les utilisateurs selon les besoins du projet.

admin/
├── index.php
├── utilisateurs.php
├── ajouter.php
├── modifier.php
└── supprimer.php

6. CRUD sécurisé

Chaque action doit vérifier la session, le rôle, les données reçues et utiliser des requêtes préparées.

7. Code d'autorisation réutilisable

function requireAdmin(): void {
    if (($_SESSION['role'] ?? '') !== 'admin') {
        http_response_code(403);
        exit('Accès interdit');
    }
}

8. Erreurs HTTP

  • 401 : authentification nécessaire selon le contexte.
  • 403 : accès refusé.
  • 404 : ressource introuvable.
  • 500 : erreur serveur.
