1. Sujet

Créer une plateforme de gestion de formations GOMA PRO Devs. Un visiteur consulte les formations, un étudiant crée un compte et se connecte, puis un administrateur gère les données.

  • Inscription.
  • Connexion.
  • Déconnexion.
  • Dashboard étudiant.
  • Sessions.
  • Rôles user/admin.
  • Dashboard administrateur.
  • CRUD des formations.
  • Validation des formulaires.
  • Messages d'erreur compréhensibles.

4. Base de données

CREATE DATABASE goma_app CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE TABLE utilisateurs (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  nom VARCHAR(100) NOT NULL,
  email VARCHAR(190) NOT NULL UNIQUE,
  mot_de_passe VARCHAR(255) NOT NULL,
  role VARCHAR(20) NOT NULL DEFAULT 'user'
);

CREATE TABLE formations (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  titre VARCHAR(150) NOT NULL,
  description TEXT NOT NULL
);

5. Installation locale

  1. Installer XAMPP.
  2. Démarrer Apache et MySQL.
  3. Créer le dossier du projet dans htdocs.
  4. Créer la base dans phpMyAdmin ou avec SQL.
  5. Configurer PDO.
  6. Ouvrir le projet avec http://localhost/....

6. Inscription

$hash = password_hash($password, PASSWORD_DEFAULT);
$stmt = $pdo->prepare(
  'INSERT INTO utilisateurs (nom, email, mot_de_passe) VALUES (:nom, :email, :hash)'
);
$stmt->execute(['nom' => $nom, 'email' => $email, 'hash' => $hash]);

7. Connexion

session_start();
if ($user && password_verify($password, $user['mot_de_passe'])) {
    session_regenerate_id(true);
    $_SESSION['user_id'] = $user['id'];
    $_SESSION['role'] = $user['role'];
    header('Location: dashboard.php');
    exit;
}

8. Protection

session_start();
if (!isset($_SESSION['user_id'])) {
    header('Location: login.php');
    exit;
}

if (($_SESSION['role'] ?? '') !== 'admin') {
    http_response_code(403);
    exit('Accès interdit');
}
