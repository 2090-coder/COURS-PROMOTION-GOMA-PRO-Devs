WEB BACKEND · CHAPITRE 10

Projet final : application PHP + MySQL

Le projet final reprend tout le parcours dans l'ordre. L'étudiant construit une petite plateforme de gestion avec pages HTML, PHP, formulaires, base de données, inscription, connexion, sessions et espace d'administration.

Étape 1 — Préparer

  • Installer PHP et MySQL.
  • Créer le dossier du projet.
  • Créer la base de données.
  • Préparer la structure des dossiers.

Étape 2 — Construire l'interface

  • Accueil.
  • Inscription.
  • Connexion.
  • Dashboard.
  • Administration.

Étape 3 — Construire le backend

  1. Traiter les formulaires.
  2. Valider les données.
  3. Connecter PHP à MySQL.
  4. Créer les opérations CRUD.
  5. Gérer les redirections.

Étape 4 — Authentification

  1. Créer un compte.
  2. Hasher le mot de passe.
  3. Vérifier l'identifiant à la connexion.
  4. Créer la session.
  5. Protéger le dashboard.
  6. Gérer la déconnexion.

Étape 5 — Administration

Créer une page réservée au rôle administrateur pour consulter, ajouter, modifier et supprimer les données nécessaires au projet.

Étape 6 — Tests

  • Tester les formulaires vides et invalides.
  • Tester un email déjà utilisé.
  • Tester un mauvais mot de passe.
  • Tester une page protégée sans connexion.
  • Tester un utilisateur normal face à une page administrateur.
  • Tester les opérations CRUD.

Livrable

Le projet doit être accompagné d'un README expliquant l'installation, la configuration locale, la création de la base, le lancement du serveur et les comptes de test.

Évaluation / 100

  • Installation et fonctionnement : 10
  • PHP et HTML : 15
  • Base de données : 15
  • Formulaires et redirections : 10
  • Inscription et connexion : 15
  • Sessions et autorisations : 15
  • CRUD : 10
  • Organisation, tests et documentation : 10
