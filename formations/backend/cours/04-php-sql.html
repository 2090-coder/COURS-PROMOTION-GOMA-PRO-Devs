WEB BACKEND · CHAPITRE 04

Formulaires, validation et redirections

Une application Web doit recevoir les données d'un utilisateur, les vérifier, effectuer une action puis souvent rediriger vers une autre page.

1. Formulaire HTML

<form method="post" action="traitement.php">
  <label>Nom</label>
  <input name="nom" required>
  <button type="submit">Envoyer</button>
</form>

2. Recevoir POST

<?php
$nom = trim($_POST['nom'] ?? '');

if ($nom === '') {
    exit('Nom obligatoire');
}

echo htmlspecialchars($nom, ENT_QUOTES, 'UTF-8');

3. GET et POST

  • GET est souvent utilisé pour demander une ressource ou transmettre des paramètres dans l'URL.
  • POST est utilisé pour envoyer des données dans le corps de la requête.
  • Dans les deux cas, le serveur doit valider les données.

4. Redirection

<?php
header('Location: resultat.php');
exit;

La redirection demande au navigateur de faire une nouvelle requête vers une autre URL. On utilise généralement exit juste après pour arrêter le traitement.

5. Message après redirection

Pour transmettre un état d'une requête à la suivante, les sessions peuvent être utilisées. Nous les étudierons avec l'authentification.

TP

  1. Créer un formulaire d'inscription simple sans base de données.
  2. Vérifier que les champs obligatoires sont remplis.
  3. Afficher un message d'erreur compréhensible.
  4. Après réussite, rediriger vers une page de confirmation.
