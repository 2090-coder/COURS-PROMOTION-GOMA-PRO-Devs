PHP + SQL : construire un CRUD

PDO permet à PHP de communiquer avec une base relationnelle. Les requêtes préparées réduisent les risques d'injection SQL.

Connexion PDO

$pdo = new PDO(
    'mysql:host=localhost;dbname=goma_pro_devs;charset=utf8mb4',
    $user,
    $password,
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

Requête préparée

$stmt = $pdo->prepare(
    'SELECT id, nom FROM etudiants WHERE email = :email'
);
$stmt->execute(['email' => $email]);
$etudiant = $stmt->fetch(PDO::FETCH_ASSOC);

CRUD

  • Create : créer.
  • Read : lire.
  • Update : modifier.
  • Delete : supprimer.

TP

  1. Créer une table d'étudiants.
  2. Réaliser les quatre opérations CRUD.
  3. Ajouter validation et gestion des erreurs.
  4. Tester les cas invalides.
