Installer et apprendre MySQL

Une application réelle doit souvent conserver des informations. MySQL est un système de gestion de base de données relationnelle. Ici, on apprend d'abord à créer et comprendre les données avant de les connecter à PHP.

1. Installer l'environnement de base de données

Installez un serveur MySQL adapté à votre environnement de cours. Vous pouvez aussi utiliser un environnement local qui fournit MySQL et un outil d'administration. Notez le nom du serveur, le port, l'utilisateur et le mot de passe de développement.

2. Créer une base

CREATE DATABASE goma_pro_devs
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;

3. Créer une table

USE goma_pro_devs;

CREATE TABLE utilisateurs (
  id INT PRIMARY KEY AUTO_INCREMENT,
  nom VARCHAR(100) NOT NULL,
  email VARCHAR(190) NOT NULL UNIQUE,
  mot_de_passe VARCHAR(255) NOT NULL,
  role VARCHAR(30) NOT NULL DEFAULT 'user',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

4. Ajouter et lire

INSERT INTO utilisateurs (nom, email, mot_de_passe)
VALUES ('Aline', 'aline@example.test', 'HASH_A_METTRE_DEPUIS_PHP');

SELECT id, nom, email, role
FROM utilisateurs
ORDER BY id DESC;

Un mot de passe réel ne doit jamais être enregistré en clair. Le hash sera produit par PHP dans le chapitre sur l'inscription.

5. Modifier et supprimer

UPDATE utilisateurs
SET nom = 'Aline K.'
WHERE id = 1;

DELETE FROM utilisateurs
WHERE id = 1;

6. Relations

Les applications peuvent contenir plusieurs tables reliées par des clés. Nous utiliserons ensuite ces relations pour construire une application complète.
