MySQL et bases de données

Une application doit conserver des informations. Nous découvrons la base, les tables et SQL avant de connecter PHP.

1. Démarrer MySQL avec XAMPP

Ouvrir XAMPP Control Panel puis cliquer sur Start à côté de MySQL. L'outil phpMyAdmin peut servir à administrer la base localement.

2. Créer une base

CREATE DATABASE goma_app CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
USE goma_app;

3. Créer une table

CREATE TABLE utilisateurs (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  nom VARCHAR(100) NOT NULL,
  email VARCHAR(190) NOT NULL UNIQUE,
  mot_de_passe VARCHAR(255) NOT NULL,
  role VARCHAR(20) NOT NULL DEFAULT 'user',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

4. INSERT

INSERT INTO utilisateurs (nom, email, mot_de_passe)
VALUES ('Aline', 'aline@example.test', 'HASH_ICI');

Le mot de passe réel sera hashé par PHP. Ne jamais stocker un mot de passe réel en clair.

5. SELECT

SELECT id, nom, email, role
FROM utilisateurs
ORDER BY id DESC;

6. WHERE

SELECT id, nom, email
FROM utilisateurs
WHERE email = 'aline@example.test';

7. UPDATE

UPDATE utilisateurs
SET nom = 'Aline K.'
WHERE id = 1;

8. DELETE

DELETE FROM utilisateurs
WHERE id = 1;

Toujours vérifier le WHERE avant une modification ou suppression.

9. Relations

CREATE TABLE formations (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  titre VARCHAR(150) NOT NULL
);

CREATE TABLE inscriptions (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  utilisateur_id INT UNSIGNED NOT NULL,
  formation_id INT UNSIGNED NOT NULL,
  FOREIGN KEY (utilisateur_id) REFERENCES utilisateurs(id),
  FOREIGN KEY (formation_id) REFERENCES formations(id)
);

10. CRUD

Create = INSERT, Read = SELECT, Update = UPDATE, Delete = DELETE.
