WEB BACKEND · CHAPITRE 05

Authentification et sécurité

Un backend doit vérifier l'identité et les droits de l'utilisateur sans faire confiance aux données envoyées par le navigateur.

Mots de passe

$hash = password_hash($password, PASSWORD_DEFAULT);

if (password_verify($password, $hash)) {
    echo "Mot de passe correct";
}

Sessions

session_start();
$_SESSION['user_id'] = $user['id'];

Principes de sécurité

  • Hacher les mots de passe avec les fonctions prévues par PHP.
  • Utiliser des requêtes préparées.
  • Valider les entrées côté serveur.
  • Contrôler les autorisations à chaque action sensible.
  • Ne jamais stocker de secrets dans Git.
  • Utiliser HTTPS en production.

TP

  1. Créer une page de connexion dans un environnement local.
  2. Ajouter une session après authentification.
  3. Protéger une page réservée aux utilisateurs connectés.
  4. Ajouter une déconnexion.
