WEB BACKEND · CHAPITRE 02

Programmer en PHP

Maintenant que PHP fonctionne, nous apprenons à programmer progressivement avant de connecter une base de données.

1. Variables

<?php
$nom = "Aline";
$age = 20;
$connecte = true;

echo $nom;
echo $age;
?>

2. Types

PHP manipule notamment les chaînes, nombres, booléens, tableaux et valeurs nulles.

3. Opérateurs

$a = 10;
$b = 3;
$somme = $a + $b;
$produit = $a * $b;
$egal = ($a === $b);

4. Conditions

if ($age >= 18) {
    echo "Majeur";
} else {
    echo "Mineur";
}

5. Boucles

for ($i = 1; $i <= 5; $i++) {
    echo "Numéro : $i<br>";
}

$fruits = ["Mangue", "Banane", "Orange"];
foreach ($fruits as $fruit) {
    echo $fruit . "<br>";
}

6. Tableaux associatifs

$utilisateur = [
    'nom' => 'Aline',
    'ville' => 'Goma'
];

echo $utilisateur['nom'];

7. Fonctions

function saluer(string $nom): string {
    return "Bonjour " . $nom;
}

echo saluer('Aline');

8. PHP + HTML

<h1>Bienvenue</h1>
<p>Bonjour <?= htmlspecialchars($nom, ENT_QUOTES, 'UTF-8') ?></p>

Quand une donnée vient d'un utilisateur, il faut apprendre à l'échapper avant de l'afficher dans HTML.

9. Débogage simple

var_dump($utilisateur);
print_r($fruits);

10. Mini-programme

<?php
$prix = 20;
$quantite = 3;
$total = $prix * $quantite;
?>
<h1>Commande</h1>
<p>Total : <?= $total ?> $</p>

TP

  1. Créer trois variables.
  2. Faire une condition de réussite avec une note.
  3. Afficher les nombres de 1 à 10.
  4. Créer un tableau de cinq étudiants.
  5. Créer une fonction qui calcule un total.
  6. Afficher le résultat dans une page HTML.

Questions

  2. Quelle différence entre == et === ?
  3. À quoi sert une fonction ?
  4. Pourquoi utiliser htmlspecialchars() lors de l'affichage de données utilisateur ?
