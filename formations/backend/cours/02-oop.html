PHP orienté objet

La programmation orientée objet permet de regrouper données et comportements dans des classes bien organisées.

Classe et objet

class Etudiant {
    public function __construct(
        public string $nom,
        private float $note
    ) {}

    public function estAdmis(): bool {
        return $this->note >= 10;
    }
}

$etudiant = new Etudiant("Aline", 14);
var_dump($etudiant->estAdmis());

Concepts

  • Encapsulation et visibilité public, protected, private.
  • Héritage pour spécialiser une classe.
  • Interfaces pour définir un contrat.
  • Composition pour assembler des objets.
