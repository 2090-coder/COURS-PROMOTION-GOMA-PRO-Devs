Programmer en PHP : les bases

Maintenant que PHP fonctionne, on apprend à programmer progressivement : afficher, stocker, calculer, décider, répéter et créer des fonctions.

1. Structure d'un script

<?php
echo "Bonjour";

2. Variables et types

$nom = "Aline";
$age = 20;
$note = 15.5;
$admis = true;

echo $nom;

3. Conditions

if ($note >= 10) {
    echo "Admis";
} else {
    echo "À améliorer";
}

4. Boucles

for ($i = 1; $i <= 5; $i++) {
    echo "Ligne $i<br>";
}

5. Tableaux

$etudiants = ["Aline", "Jean", "Sarah"];
foreach ($etudiants as $etudiant) {
    echo $etudiant . "<br>";
}

6. Fonctions

function saluer(string $nom): string {
    return "Bonjour " . $nom;
}

echo saluer("Aline");

TP

  1. Créer un programme qui calcule la moyenne de trois notes.
  2. Afficher une liste de cinq étudiants avec une boucle.
  3. Créer une fonction qui indique si une note est réussie.
  4. Tester chaque programme avec plusieurs valeurs.

Questions

  1. Qu'est-ce qu'une variable ?
  2. À quoi sert if ?
  3. Quelle différence entre for et foreach ?
  4. Pourquoi utiliser une fonction ?
