Connecter PHP à MySQL avec PDO

Nous allons maintenant relier les deux parties : PHP traite les demandes et MySQL conserve les données. PDO fournit l'interface PHP pour accéder à MySQL.

1. Créer la connexion

<?php
$pdo = new PDO(
    'mysql:host=localhost;dbname=goma_pro_devs;charset=utf8mb4',
    'root',
    'mot_de_passe_local',
    [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]
);

En pratique, les identifiants de production ne doivent pas être écrits directement dans le code source.

2. Lire les utilisateurs

$stmt = $pdo->query(
    'SELECT id, nom, email FROM utilisateurs ORDER BY id DESC'
);

$utilisateurs = $stmt->fetchAll(PDO::FETCH_ASSOC);

3. Requêtes préparées

$stmt = $pdo->prepare(
    'SELECT id, nom, email FROM utilisateurs WHERE email = :email'
);
$stmt->execute(['email' => $email]);
$user = $stmt->fetch(PDO::FETCH_ASSOC);

Les requêtes préparées permettent de séparer les paramètres des instructions SQL et constituent une pratique essentielle pour éviter les injections SQL.

4. CRUD

  • Create : INSERT
  • Read : SELECT
  • Update : UPDATE
  • Delete : DELETE
