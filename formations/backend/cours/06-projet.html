Connecter PHP à MySQL avec PDO

Nous passons maintenant de SQL seul à une vraie application PHP capable de lire et modifier la base.

1. Connexion

<?php
$pdo = new PDO(
    'mysql:host=localhost;dbname=goma_app;charset=utf8mb4',
    'root',
    ''
);
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);

Les identifiants ci-dessus sont des exemples de développement local. En production, utiliser une configuration sécurisée.

2. SELECT avec requête préparée

$stmt = $pdo->prepare(
    'SELECT id, nom, email FROM utilisateurs WHERE email = :email'
);
$stmt->execute(['email' => $email]);
$user = $stmt->fetch(PDO::FETCH_ASSOC);

3. Pourquoi les requêtes préparées ?

Elles permettent de séparer les paramètres des instructions SQL et constituent une pratique importante pour éviter de construire des requêtes dangereuses à partir de données utilisateur.

4. INSERT

$stmt = $pdo->prepare(
  'INSERT INTO utilisateurs (nom, email, mot_de_passe) VALUES (:nom, :email, :hash)'
);
$stmt->execute([
  'nom' => $nom,
  'email' => $email,
  'hash' => $hash
]);

5. Afficher dans HTML

<?php foreach ($utilisateurs as $user): ?>
  <article>
    <h2><?= htmlspecialchars($user['nom']) ?></h2>
    <p><?= htmlspecialchars($user['email']) ?></p>
  </article>
<?php endforeach; ?>

6. CRUD

  • Create : INSERT.
  • Read : SELECT.
  • Update : UPDATE.
  • Delete : DELETE.

7. Gestion des erreurs

try {
    $pdo = new PDO($dsn, $user, $password);
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
} catch (PDOException $e) {
    http_response_code(500);
    exit('Impossible de se connecter à la base.');
}

En production, ne pas afficher le message interne complet de l'exception aux visiteurs.
