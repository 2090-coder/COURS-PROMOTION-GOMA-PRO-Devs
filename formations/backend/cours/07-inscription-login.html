WEB BACKEND · CHAPITRE 07

Inscription, connexion et sessions

C'est ici que nous construisons le mécanisme classique : un visiteur crée un compte, PHP enregistre ses informations, puis la page de connexion recherche le compte et compare le mot de passe correctement.

1. Inscription : recevoir les données

$nom = trim($_POST['nom'] ?? '');
$email = trim($_POST['email'] ?? '');
$password = $_POST['password'] ?? '';

if ($nom === '' || !filter_var($email, FILTER_VALIDATE_EMAIL)) {
    exit('Données invalides');
}

2. Ne jamais enregistrer le mot de passe en clair

$hash = password_hash($password, PASSWORD_DEFAULT);

La base conserve le hash, pas le mot de passe original. PHP fournit password_hash() pour produire ce hash.

3. Enregistrer le compte

$stmt = $pdo->prepare(
  'INSERT INTO utilisateurs (nom, email, mot_de_passe) VALUES (:nom, :email, :hash)'
);
$stmt->execute([
  'nom' => $nom,
  'email' => $email,
  'hash' => $hash
]);

L'email doit être unique dans la base. Il faut gérer proprement le cas où l'utilisateur existe déjà.

4. Connexion : retrouver le compte

$stmt = $pdo->prepare(
  'SELECT id, nom, email, mot_de_passe, role FROM utilisateurs WHERE email = :email'
);
$stmt->execute(['email' => $email]);
$user = $stmt->fetch(PDO::FETCH_ASSOC);

5. Comparer le mot de passe

if ($user && password_verify($password, $user['mot_de_passe'])) {
    // Identifiants corrects
} else {
    // Identifiants incorrects
}

On ne compare donc pas le mot de passe à une valeur stockée en clair. password_verify() vérifie le mot de passe fourni contre le hash enregistré.

6. Garder l'utilisateur connecté

session_start();
$_SESSION['user_id'] = $user['id'];
$_SESSION['role'] = $user['role'];

7. Déconnexion

session_start();
$_SESSION = [];
session_destroy();
header('Location: login.php');
exit;
