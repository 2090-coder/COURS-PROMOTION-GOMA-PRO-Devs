WEB BACKEND · CHAPITRE 07

Inscription, connexion et sessions

Nous construisons maintenant le parcours complet : inscription, recherche du compte, vérification du mot de passe et session utilisateur.

1. Formulaire d'inscription

<form method="post" action="register.php">
  <label for="nom">Nom</label>
  <input id="nom" name="nom" required>
  <label for="email">Email</label>
  <input id="email" name="email" type="email" required>
  <label for="password">Mot de passe</label>
  <input id="password" name="password" type="password" required>
  <button type="submit">Créer le compte</button>
</form>

2. Valider les données

$nom = trim($_POST['nom'] ?? '');
$email = trim($_POST['email'] ?? '');
$password = $_POST['password'] ?? '';

if ($nom === '' || !filter_var($email, FILTER_VALIDATE_EMAIL) || $password === '') {
    exit('Données invalides');
}

3. Hasher le mot de passe

$hash = password_hash($password, PASSWORD_DEFAULT);

La base conserve le hash et non le mot de passe original.

4. Enregistrer le compte

$stmt = $pdo->prepare(
  'INSERT INTO utilisateurs (nom, email, mot_de_passe) VALUES (:nom, :email, :hash)'
);
$stmt->execute([
  'nom' => $nom,
  'email' => $email,
  'hash' => $hash
]);

5. Connexion : retrouver le compte

$stmt = $pdo->prepare(
  'SELECT id, nom, email, mot_de_passe, role FROM utilisateurs WHERE email = :email'
);
$stmt->execute(['email' => $email]);
$user = $stmt->fetch(PDO::FETCH_ASSOC);

6. Vérifier le mot de passe

if ($user && password_verify($password, $user['mot_de_passe'])) {
    echo 'Connexion réussie';
} else {
    echo 'Identifiants incorrects';
}

7. Créer la session

session_start();

session_regenerate_id(true);
$_SESSION['user_id'] = $user['id'];
$_SESSION['role'] = $user['role'];

8. Vérifier une session

session_start();
if (!isset($_SESSION['user_id'])) {
    header('Location: login.php');
    exit;
}

9. Déconnexion

session_start();
$_SESSION = [];
session_destroy();
header('Location: login.php');
exit;

10. Règles essentielles

  • Ne jamais stocker les mots de passe en clair.
  • Utiliser des requêtes préparées.
  • Valider les données côté serveur.
  • Regénérer l'identifiant de session après authentification.
  • Ne pas afficher de secrets dans les erreurs.
