Projet final intégrateur

Mettre ensemble algorithmique, programmation, base de données, système, réseau et sécurité dans un projet réel de niveau étudiant.

Projet proposé : plateforme de gestion

Créer une application permettant de gérer des étudiants, leurs formations, leurs inscriptions et leurs résultats.

1. Fonctionnalités

  • Créer et consulter des étudiants.
  • Créer des formations.
  • Enregistrer les inscriptions.
  • Rechercher et filtrer les données.
  • Générer un tableau de bord simple.
  • Prévoir une authentification et des rôles.

2. Architecture

Frontend : interface web. Backend : API ou application serveur. Base de données : stockage relationnel. Système : environnement Linux ou Windows de développement. Réseau : accès local sécurisé.

3. Organisation Git

git switch -c feature/etudiants
git add .
git commit -m "Ajoute la gestion des étudiants"

4. Sécurité

  • Hacher les mots de passe avec une fonction adaptée.
  • Valider les données reçues.
  • Utiliser des requêtes paramétrées.
  • Protéger les sessions.
  • Ne jamais publier de secrets.

5. Livrables

  1. Code source organisé.
  2. Base de données et script de création.
  3. README d'installation.
  4. Documentation technique.
  5. Présentation du projet.
  6. Démonstration fonctionnelle.

Évaluation / 100

  • Fonctionnalités : 30 points
  • Qualité du code : 15 points
  • Base de données : 15 points
  • Interface et ergonomie : 10 points
  • Sécurité : 15 points
  • Git et documentation : 10 points
  • Présentation : 5 points

Questions de soutenance

  1. Pourquoi avez-vous choisi cette architecture ?
  2. Comment les données circulent-elles entre interface, serveur et base ?
  3. Comment protégez-vous les comptes utilisateurs ?
  4. Comment testeriez-vous l'application ?
  5. Que feriez-vous pour améliorer le projet en production ?
