INFORMATIQUE COMPLET · CHAPITRE 09

Dépannage, réseau et sécurité

Diagnostiquer les problèmes courants d'un poste Windows et appliquer les bonnes pratiques de sécurité.

1. Méthode de dépannage

  1. Identifier le problème.
  2. Reproduire le problème.
  3. Formuler une hypothèse.
  4. Tester une solution.
  5. Vérifier le résultat.
  6. Documenter l'intervention.

2. Problèmes courants

  • Ordinateur lent
  • Application bloquée
  • Problème audio
  • Problème d'affichage
  • USB non reconnu
  • Windows qui ne démarre pas correctement

3. Réseau

Comprendre IP, masque, passerelle et DNS et utiliser des outils de diagnostic sur son propre réseau ou un environnement autorisé.

ipconfig
ping 192.168.1.1
nslookup example.com
tracert example.com

4. Sécurité Windows

  • Windows Update
  • Windows Security
  • Pare-feu
  • Comptes et permissions
  • Sauvegardes
  • Prudence avec les téléchargements et pièces jointes

5. Journalisation

Découvrir l'Observateur d'événements et utiliser les informations disponibles pour comprendre une panne.

Travaux pratiques

  1. Diagnostiquer une panne réseau simulée.
  2. Analyser une application lente avec le Gestionnaire des tâches.
  3. Construire une checklist de sécurité.
  4. Rédiger un rapport d'intervention.
