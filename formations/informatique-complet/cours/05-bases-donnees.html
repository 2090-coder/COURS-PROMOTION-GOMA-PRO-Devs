Bases de données et SQL

Modéliser, créer, interroger et maintenir des données structurées.

1. Modèle relationnel

Une base relationnelle organise les informations en tables composées de lignes et de colonnes. Une clé primaire identifie chaque ligne de façon unique.

2. Création d'une table

CREATE TABLE etudiants (
    id INTEGER PRIMARY KEY,
    nom VARCHAR(100) NOT NULL,
    age INTEGER,
    email VARCHAR(150) UNIQUE
);

3. Requêtes essentielles

SELECT nom, age FROM etudiants;
INSERT INTO etudiants (id, nom, age) VALUES (1, 'Amina', 19);
UPDATE etudiants SET age = 20 WHERE id = 1;
DELETE FROM etudiants WHERE id = 1;

4. Relations et JOIN

Les relations permettent de relier plusieurs tables. Un JOIN récupère des informations liées selon une condition commune.

SELECT e.nom, f.nom
FROM etudiants e
JOIN formations f ON e.formation_id = f.id;

5. Bonnes pratiques

  • Choisir des clés cohérentes.
  • Éviter les doublons inutiles.
  • Utiliser des requêtes paramétrées côté application.
  • Prévoir des sauvegardes.

Travaux pratiques

  1. Créer une base de gestion des étudiants.
  2. Créer les tables étudiants, formations et inscriptions.
  3. Écrire des requêtes SELECT, INSERT, UPDATE et DELETE.
  4. Faire une requête JOIN entre étudiants et formations.
