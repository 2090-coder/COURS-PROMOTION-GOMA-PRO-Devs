Programmation

Passer de l'algorithme au code avec Python et comprendre les notions communes aux langages modernes.

1. Premier programme

nom = "GOMA PRO Devs"
print("Bonjour", nom)

2. Conditions et boucles

note = 72
if note >= 50:
    print("Réussi")
else:
    print("À reprendre")

for i in range(1, 6):
    print(i)

3. Fonctions

def moyenne(a, b, c):
    return (a + b + c) / 3

4. Programmation orientée objet

Une classe décrit une structure et des comportements. Un objet est une instance de cette classe.

class Etudiant:
    def __init__(self, nom):
        self.nom = nom

    def presenter(self):
        print("Étudiant :", self.nom)

5. Bonnes pratiques

  • Choisir des noms explicites.
  • Découper le programme en fonctions.
  • Éviter la duplication inutile.
  • Tester les cas normaux et les erreurs.
  • Documenter les parties importantes.

Travaux pratiques

  1. Créer un programme de calculatrice.
  2. Créer un gestionnaire simple de notes avec une liste.
  3. Créer une classe Etudiant avec nom, âge et moyenne.
  4. Ajouter une validation des données saisies.
