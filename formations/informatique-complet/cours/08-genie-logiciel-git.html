INFORMATIQUE COMPLET · CHAPITRE 08

Génie logiciel et Git

Apprendre à organiser un projet, travailler proprement avec Git et maintenir un code compréhensible.

1. Cycle de développement

Un projet passe généralement par l'analyse des besoins, la conception, l'implémentation, les tests, la mise en production et la maintenance.

2. Git : premiers pas

git init
git status
git add .
git commit -m "Premier commit"
git log

3. Dépôt distant

git remote add origin URL_DU_DEPOT
git push -u origin main

4. Branches

git branch feature-login
git switch feature-login
# travailler...
git add .
git commit -m "Ajoute la connexion"

5. Qualité

  • Convention de nommage.
  • Commentaires utiles, pas excessifs.
  • Tests automatisés lorsque possible.
  • Commits petits et explicites.
  • README et documentation à jour.

Travaux pratiques

  1. Créer un dépôt Git pour un mini-projet.
  2. Faire au moins cinq commits propres.
  3. Créer une branche de fonctionnalité.
  4. Rédiger un README avec installation et utilisation.
