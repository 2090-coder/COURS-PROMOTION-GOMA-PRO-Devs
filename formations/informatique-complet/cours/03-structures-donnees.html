INFORMATIQUE COMPLET · CHAPITRE 03

Structures de données

Organiser efficacement les données pour faciliter leur traitement et améliorer les performances des programmes.

1. Listes et tableaux

notes = [65, 72, 81, 55]
print(notes[0])
notes.append(90)

2. Tuples et ensembles

Un tuple convient aux données qui ne doivent pas être modifiées. Un ensemble élimine les doublons et facilite les opérations d'appartenance.

3. Dictionnaires

etudiant = {
    "nom": "Amina",
    "age": 19,
    "moyenne": 76
}
print(etudiant["nom"])

4. Piles et files

Une pile suit le principe LIFO : dernier entré, premier sorti. Une file suit FIFO : premier entré, premier sorti.

5. Recherche et tri

La recherche linéaire parcourt les éléments un à un. Le tri réorganise les données selon une règle. Pour de grands volumes, le choix de l'algorithme influence fortement le temps d'exécution.

Travaux pratiques

  1. Créer une liste de 10 notes et calculer minimum, maximum et moyenne.
  2. Compter les valeurs répétées dans une liste.
  3. Créer une file de tâches et traiter les tâches dans l'ordre.
  4. Comparer une recherche linéaire avec une recherche dans des données triées.
