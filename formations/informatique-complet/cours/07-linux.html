Linux et administration

Maîtriser les bases de l'administration Linux : fichiers, permissions, processus, services, utilisateurs et logs.

1. Navigation

pwd
ls -la
cd /var/log
mkdir projet
cp fichier.txt sauvegarde.txt

2. Permissions

Linux distingue le propriétaire, le groupe et les autres utilisateurs. Les permissions classiques sont lecture (r), écriture (w) et exécution (x).

ls -l script.sh
chmod u+x script.sh

3. Processus et services

ps aux
systemctl status nom-service
journalctl -u nom-service

4. Utilisateurs

Un administrateur doit appliquer le principe du moindre privilège : chaque compte reçoit uniquement les droits nécessaires.

5. Sauvegardes et logs

Les journaux permettent d'analyser les événements du système. Une stratégie de sauvegarde doit prévoir plusieurs copies et des tests réguliers de restauration.

Travaux pratiques

  1. Créer un utilisateur de laboratoire et un groupe.
  2. Créer un dossier partagé avec des permissions définies.
  3. Identifier un processus et consulter ses informations.
  4. Lire les journaux d'un service dans une machine de test.
