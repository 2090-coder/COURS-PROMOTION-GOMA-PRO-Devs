Guide de progression de l'étudiant

Ce guide accompagne l'étudiant pendant les 10 chapitres. L'objectif est de ne pas seulement lire le cours, mais de pratiquer, corriger ses erreurs et construire progressivement un projet.

Ordre recommandé

  1. Algorithmique : comprendre le problème avant d'écrire du code.
  2. Programmation : transformer les algorithmes en programmes Python.
  3. Structures de données : apprendre à organiser et rechercher les informations.
  4. Systèmes : comprendre CPU, mémoire, stockage, processus et système d'exploitation.
  5. Bases de données : modéliser, enregistrer et interroger les données.
  6. Réseaux : comprendre comment les machines communiquent.
  7. Linux : administrer un environnement de travail.
  8. Génie logiciel et Git : organiser le développement et conserver l'historique du code.
  9. Sécurité : protéger les comptes, données, applications et systèmes.
  10. Projet final : réunir toutes les compétences.

Méthode de travail pour chaque chapitre

  1. Lire l'explication une première fois.
  2. Recopier les exemples et les exécuter.
  3. Modifier volontairement une partie du code pour observer le résultat.
  4. Réaliser le TP sans copier la solution.
  5. Répondre aux questions de révision.
  6. Noter les erreurs rencontrées et leur correction.

Checklist

  • □ Je peux expliquer le concept avec mes propres mots.
  • □ Je peux écrire un exemple sans regarder le cours.
  • □ J'ai réalisé le TP.
  • □ J'ai testé les cas normaux et les erreurs.
  • □ J'ai répondu aux questions.
  • □ J'ai enregistré mon travail dans Git.

Objectif final

À la fin du parcours, l'étudiant doit être capable d'analyser un problème, proposer une architecture, développer une solution, stocker les données, utiliser Git, documenter son travail et présenter un projet fonctionnel.
