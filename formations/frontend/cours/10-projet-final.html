WEB FRONTEND · CHAPITRE 10

Projet final professionnel

Réaliser une application web complète, responsive, accessible et publiée en ligne.

Projet

Créer un site professionnel ou une application web répondant à un besoin réel.

Exigences

  • HTML sémantique.
  • Design responsive.
  • JavaScript interactif.
  • Formulaire avec validation.
  • Utilisation d'une API ou de données JSON.
  • Accessibilité de base.
  • Git et documentation.
  • Déploiement fonctionnel.

Étapes

  1. Définir le besoin.
  2. Faire la maquette.
  3. Construire la structure HTML.
  4. Créer le design CSS.
  5. Ajouter les interactions JavaScript.
  6. Tester sur plusieurs tailles d'écran.
  7. Corriger les erreurs.
  8. Publier.

Évaluation / 100

  • Fonctionnalités : 30
  • HTML/CSS : 20
  • JavaScript : 20
  • Responsive et accessibilité : 10
  • Qualité et Git : 10
  • Présentation : 10
