CSS : styliser et organiser l'interface

CSS contrôle les couleurs, dimensions, espacements, positions et la mise en page.

Concepts fondamentaux

  • Sélecteurs et spécificité.
  • Box model : contenu, padding, border, margin.
  • Unités : px, %, rem, vh et vw.
  • Flexbox pour les mises en page en une dimension.
  • Grid pour les mises en page en deux dimensions.
  • Media queries pour le responsive design.

Exemple

.carte {
  max-width: 600px;
  margin: 0 auto;
  padding: 24px;
  border: 1px solid #ddd;
  border-radius: 12px;
}

.grille {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

@media (max-width: 700px) {
  .grille { grid-template-columns: 1fr; }
}

TP

  1. Transformer une page HTML simple en carte moderne.
  2. Créer une grille de trois cartes.
  3. Adapter la grille aux téléphones.
  4. Tester avec les outils développeur du navigateur.
