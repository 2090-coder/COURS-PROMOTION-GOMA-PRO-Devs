JavaScript : programmer dans le navigateur

JavaScript permet d'ajouter de la logique et de rendre une interface interactive.

Variables et conditions

const nom = "Étudiant";
let note = 15;

if (note >= 10) {
  console.log(`${nom} a réussi.`);
} else {
  console.log(`${nom} doit progresser.`);
}

Boucles, fonctions et tableaux

function moyenne(notes) {
  const total = notes.reduce((somme, note) => somme + note, 0);
  return total / notes.length;
}

const notes = [12, 15, 18];
console.log(moyenne(notes));

Bonnes pratiques

  • Utiliser const par défaut et let si la valeur change.
  • Donner des noms explicites aux variables.
  • Découper les traitements en fonctions courtes.
  • Valider les données avant de les utiliser.
