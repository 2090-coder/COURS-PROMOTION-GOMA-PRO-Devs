JavaScript : programmer et interagir avec le HTML

Dans ce chapitre, JavaScript est appris dans son environnement naturel pour le frontend : le navigateur. L'objectif est de programmer puis de faire communiquer JavaScript avec la page HTML.

1. Premier programme : alert()

Pour voir immédiatement le résultat dans le navigateur, nous commençons avec alert().

alert("Bonjour GOMA PRO Devs !");

Une boîte de dialogue apparaît dans le navigateur. alert() est utile pour les premiers exercices et pour comprendre qu'un programme JavaScript peut produire une interaction visible.

2. Variables et alert()

const nom = "Étudiant";
let age = 18;

alert("Bonjour " + nom);
alert("Tu as " + age + " ans.");

On apprend les variables avant de les utiliser pour construire des messages interactifs.

3. Conditions et alert()

let note = 15;

if (note >= 10) {
  alert("Réussi !");
} else {
  alert("À revoir.");
}

La condition décide quel message doit être présenté à l'utilisateur.

4. Le DOM : JavaScript rencontre HTML

Le DOM représente la page HTML sous forme d'objets que JavaScript peut lire et modifier. On peut sélectionner un élément avec document.getElementById() ou avec document.querySelector(). citeturn0search7turn0search3

<p id="message">Texte initial</p>

const message = document.getElementById("message");
message.textContent = "Texte modifié par JavaScript !";

textContent permet de modifier le texte d'un élément HTML. citeturn0search0

5. Interaction avec un bouton

<button id="btn">Clique-moi</button>
<p id="resultat"></p>

<script>
const bouton = document.getElementById("btn");
const resultat = document.getElementById("resultat");

bouton.addEventListener("click", function () {
  resultat.textContent = "Le bouton a été cliqué !";
});
</script>

Ici, l'utilisateur agit sur le HTML et JavaScript réagit à l'événement click.

6. Lire une valeur dans un formulaire

<input id="nom" type="text" placeholder="Votre nom">
<button id="valider">Valider</button>

<script>
const champ = document.getElementById("nom");
const valider = document.getElementById("valider");

valider.addEventListener("click", function () {
  alert("Bonjour " + champ.value);
});
</script>

C'est une première vraie interaction entre une donnée saisie dans HTML et JavaScript.

7. Boucles, fonctions et tableaux

function afficherEtudiants(etudiants) {
  for (const etudiant of etudiants) {
    alert(etudiant);
  }
}

const etudiants = ["Amina", "David", "Salomon"];
afficherEtudiants(etudiants);

Les fonctions, tableaux et boucles sont ensuite utilisés dans les interactions avec la page.

TP progressif

  1. Afficher un message avec alert().
  2. Créer une variable contenant ton nom et l'afficher avec alert().
  3. Créer une condition qui affiche un message différent selon une note.
  4. Créer un paragraphe HTML et modifier son texte avec textContent.
  5. Créer un bouton qui change le texte d'un paragraphe.
  6. Créer un champ de nom et afficher la valeur avec alert().
  7. Créer une petite interface HTML permettant d'additionner deux nombres et d'afficher le résultat dans la page.

Important

console.log() peut rester utile pour le débogage, mais il ne sera pas notre moyen principal d'afficher le résultat dans les premiers exercices. L'objectif pédagogique est de faire comprendre à l'apprenant que JavaScript peut interagir directement avec le HTML grâce au DOM.
