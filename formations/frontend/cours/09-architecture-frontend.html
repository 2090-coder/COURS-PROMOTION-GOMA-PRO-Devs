WEB FRONTEND · CHAPITRE 09

Architecture et qualité frontend

Organiser une application frontend afin qu'elle reste compréhensible, testable et facile à maintenir.

1. Organisation

Séparer HTML, CSS, JavaScript, images et données selon le rôle de chaque fichier.

2. Composants

Identifier les éléments réutilisables : navigation, cartes, formulaires, boutons et sections.

3. Qualité du code

  • Noms explicites.
  • Fonctions courtes.
  • Éviter la duplication.
  • Commentaires utiles.
  • Gestion des erreurs.

4. Tests

Tester les formulaires, les interactions, les écrans mobiles et les cas d'erreur.

TP

  1. Réorganiser un petit projet mal structuré.
  2. Extraire les composants répétitifs.
  3. Tester les principales fonctionnalités.

Questions

  1. Pourquoi séparer les responsabilités ?
  2. Qu'est-ce qu'un composant réutilisable ?
  3. Pourquoi tester les cas d'erreur ?
