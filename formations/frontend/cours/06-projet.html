WEB FRONTEND · CHAPITRE 06

Projet intermédiaire : application de tâches

Nous allons maintenant réunir ce que nous avons appris en HTML, CSS et JavaScript pour construire progressivement une petite application interactive.

Objectif du projet

Construire une application de tâches permettant de :

  • écrire une tâche ;
  • ajouter la tâche dans la page ;
  • afficher plusieurs tâches ;
  • marquer une tâche comme terminée ;
  • supprimer une tâche ;
  • afficher le nombre de tâches ;
  • valider correctement le formulaire.

1. Comprendre la construction du projet

Notre application sera construite en trois parties :

HTML
  ↓
Structure de la page

CSS
  ↓
Présentation et mise en page

JavaScript
  ↓
Interactions et logique

JavaScript va sélectionner les éléments HTML, écouter les événements et créer ou modifier des éléments du DOM. C'est précisément le type de manipulation permis par createElement(), appendChild() et addEventListener(). citeturn0search0turn0search1turn0search7

2. Première étape : créer le HTML

Nous commençons toujours par la structure HTML avant d'écrire la logique JavaScript.

<!doctype html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Ma liste de tâches</title>
</head>
<body>
  <h1>Ma liste de tâches</h1>

  <form id="formulaire-tache">
    <input id="tache" type="text" placeholder="Écrire une tâche">
    <button type="submit">Ajouter</button>
  </form>

  <p id="message"></p>
  <p>Nombre de tâches : <strong id="compteur">0</strong></p>
  <ul id="liste-taches"></ul>
</body>
</html>

À ce stade, nous avons seulement construit la structure. Aucun JavaScript n'est encore nécessaire.

Nous pouvons maintenant améliorer la présentation.

body {

4. Sélectionner les éléments HTML

Nous allons maintenant connecter JavaScript au HTML.

const formulaire = document.querySelector("#formulaire-tache");
const champ = document.querySelector("#tache");
const liste = document.querySelector("#liste-taches");
const compteur = document.querySelector("#compteur");
const message = document.querySelector("#message");

Chaque constante contient une référence vers un élément HTML. Nous pouvons ensuite agir sur ces éléments.

5. Intercepter l'envoi du formulaire

Nous ne voulons pas que le navigateur recharge immédiatement la page.

formulaire.addEventListener("submit", function(event) {
  event.preventDefault();

  alert("Le formulaire a été envoyé !");
});

addEventListener() permet d'écouter un événement, tandis que preventDefault() permet ici de contrôler le comportement automatique du formulaire. citeturn0search3turn0search7

6. Lire ce que l'utilisateur a écrit

La valeur d'un champ texte est accessible avec .value.

formulaire.addEventListener("submit", function(event) {
  event.preventDefault();

  const texte = champ.value;

  alert(texte);
});

Fais un test : écris une tâche puis clique sur Ajouter. Le texte apparaît dans une boîte de dialogue.

7. Vérifier que la tâche n'est pas vide

formulaire.addEventListener("submit", function(event) {
  event.preventDefault();

  const texte = champ.value.trim();

  if (texte === "") {
    message.textContent = "Veuillez écrire une tâche.";
    return;
  }

  message.textContent = "Tâche correcte.";
});

trim() retire les espaces inutiles au début et à la fin du texte.

8. Créer une nouvelle ligne HTML avec JavaScript

Maintenant, nous allons réellement créer un élément HTML avec JavaScript.

const element = document.createElement("li");
element.textContent = texte;

liste.appendChild(element);

createElement() crée un nouvel élément et appendChild() l'ajoute dans le DOM. citeturn0search0turn0search2

9. Ajouter une tâche complète

Nous pouvons maintenant réunir les étapes précédentes.

formulaire.addEventListener("submit", function(event) {
  event.preventDefault();

  const texte = champ.value.trim();

  if (texte === "") {
    message.textContent = "Veuillez écrire une tâche.";
    return;
  }

  const element = document.createElement("li");
  element.textContent = texte;

  liste.appendChild(element);

  champ.value = "";
  message.textContent = "Tâche ajoutée.";
});

10. Ajouter un bouton « Terminer »

Une tâche ne doit pas seulement être affichée. L'utilisateur doit pouvoir interagir avec elle.

const element = document.createElement("li");
const texteTache = document.createElement("span");
const boutonTerminer = document.createElement("button");

texteTache.textContent = texte;
boutonTerminer.textContent = "Terminer";

element.appendChild(texteTache);
element.appendChild(boutonTerminer);
liste.appendChild(element);

Nous construisons donc une petite structure HTML directement avec JavaScript :

<li>
  <span>Ma tâche</span>
  <button>Terminer</button>
</li>

11. Rendre la tâche terminée

boutonTerminer.addEventListener("click", function() {
  texteTache.classList.toggle("terminee");
});

classList.toggle() ajoute la classe si elle n'existe pas et la retire si elle existe déjà.

12. Ajouter un bouton « Supprimer »

const boutonSupprimer = document.createElement("button");
boutonSupprimer.textContent = "Supprimer";

element.appendChild(boutonSupprimer);

boutonSupprimer.addEventListener("click", function() {
  element.remove();
});

La tâche peut maintenant être retirée de la page.

13. Compter les tâches

Nous voulons afficher le nombre de tâches présentes dans la liste.

compteur.textContent = liste.children.length;

Après une suppression, il faut également actualiser le compteur.

boutonSupprimer.addEventListener("click", function() {
  element.remove();
  compteur.textContent = liste.children.length;
});

14. Code JavaScript complet

const formulaire = document.querySelector("#formulaire-tache");
const champ = document.querySelector("#tache");
const liste = document.querySelector("#liste-taches");
const compteur = document.querySelector("#compteur");
const message = document.querySelector("#message");

formulaire.addEventListener("submit", function(event) {
  event.preventDefault();

  const texte = champ.value.trim();

  if (texte === "") {
    message.textContent = "Veuillez écrire une tâche.";
    return;
  }

  const element = document.createElement("li");
  const texteTache = document.createElement("span");
  const boutonTerminer = document.createElement("button");
  const boutonSupprimer = document.createElement("button");

  texteTache.textContent = texte;
  boutonTerminer.textContent = "Terminer";
  boutonSupprimer.textContent = "Supprimer";

  element.appendChild(texteTache);
  element.appendChild(boutonTerminer);
  element.appendChild(boutonSupprimer);
  liste.appendChild(element);

  boutonTerminer.addEventListener("click", function() {
    texteTache.classList.toggle("terminee");
  });

  boutonSupprimer.addEventListener("click", function() {
    element.remove();
    compteur.textContent = liste.children.length;
  });

  compteur.textContent = liste.children.length;
  champ.value = "";
  message.textContent = "Tâche ajoutée avec succès.";
  champ.focus();
});

17. Ce que tu viens réellement d'apprendre

  • Créer une structure avec HTML.
  • Styliser une interface avec CSS.
  • Sélectionner des éléments avec querySelector().
  • Écouter un événement avec addEventListener().
  • Lire la valeur d'un champ avec value.
  • Empêcher le comportement automatique d'un formulaire avec preventDefault().
  • Créer des éléments avec createElement().
  • Ajouter des éléments au DOM avec appendChild().
  • Modifier les classes avec classList.
  • Supprimer des éléments avec remove().
  • Construire une petite application complète.
