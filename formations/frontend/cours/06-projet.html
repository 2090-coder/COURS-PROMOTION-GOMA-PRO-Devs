WEB FRONTEND · CHAPITRE 06

Projet final : application web

Construisez une petite application complète qui démontre vos compétences HTML, CSS et JavaScript.

Cahier des charges

  • Interface responsive pour ordinateur et téléphone.
  • Navigation claire et accessible.
  • Formulaire avec validation côté client.
  • Données manipulées dynamiquement avec JavaScript.
  • Page d'erreur ou état vide.
  • Code organisé et commenté uniquement lorsque cela apporte une vraie explication.

Exemple de projets

  • Gestionnaire de tâches.
  • Catalogue de produits fictifs.
  • Tableau de bord étudiant.
  • Application de notes.

Évaluation

  1. Structure HTML et accessibilité : 20 points.
  2. Design CSS et responsive : 20 points.
  3. JavaScript et logique : 25 points.
  4. Qualité du code : 15 points.
  5. Présentation et documentation : 20 points.
