WEB FRONTEND · CHAPITRE 07

Accessibilité et SEO

Dans ce chapitre, nous allons apprendre progressivement à construire des pages faciles à utiliser, y compris au clavier et avec des technologies d'assistance, puis à améliorer leur compréhension par les moteurs de recherche.

1. Qu'est-ce que l'accessibilité web ?

L'accessibilité consiste à rendre un site utilisable par le plus grand nombre, notamment par les personnes qui ont des difficultés visuelles, auditives, motrices ou cognitives.

Bonne règle : l'accessibilité ne doit pas être ajoutée uniquement à la fin du projet. Il faut y penser dès la création de la structure HTML.

2. Utiliser le bon élément HTML

Le HTML sémantique signifie que chaque élément doit être utilisé pour son rôle réel. Par exemple, un bouton doit être un <button>, et un lien doit être un <a>.

Les éléments comme <header>, <nav>, <main>, <section>, <article> et <footer> donnent également une structure compréhensible à la page. citeturn0search0turn0search1

Exemple HTML

<header>
  <h1>GOMA PRO Devs</h1>
</header>

<nav aria-label="Navigation principale">
  <a href="index.html">Accueil</a>
  <a href="cours.html">Cours</a>
</nav>

<main>
  <section>
    <h2>Cours Frontend</h2>
    <p>Apprendre à créer des interfaces web.</p>
    <button type="button">Commencer</button>
  </section>
</main>

<footer>GOMA PRO Devs</footer>

3. Pourquoi éviter un faux bouton avec <div> ?

On pourrait écrire <div>Cliquez</div>, mais ce n'est pas un vrai contrôle interactif. Un vrai <button> possède déjà un comportement adapté au clavier et aux technologies d'assistance.

Il faut donc préférer les éléments HTML natifs avant d'ajouter des solutions plus complexes.

4. Les images et l'attribut alt

Une image informative doit avoir un texte alternatif qui explique ce qu'elle apporte au contenu. Une image uniquement décorative peut utiliser un alt="".

Exemple HTML

<img src="logo.png" alt="Logo GOMA PRO Devs">

<img src="decoration.png" alt="">

Le texte de alt doit être court, précis et utile. citeturn0search0turn0search2

5. Les formulaires accessibles

Chaque champ important doit avoir une étiquette claire. On utilise généralement <label> avec l'attribut for correspondant à l'id du champ.

Exemple HTML complet

<form>
  <label for="nom">Votre nom</label>
  <input id="nom" name="nom" type="text" required>

  <label for="email">Votre adresse e-mail</label>
  <input id="email" name="email" type="email" required>

  <button type="submit">S'inscrire</button>
</form>

Des labels explicites facilitent la compréhension et l'utilisation des formulaires, notamment avec les technologies d'assistance. citeturn0search0turn0search6

6. Navigation au clavier

Un utilisateur doit pouvoir parcourir les éléments interactifs avec le clavier. Test simple : utilisez la touche Tab dans votre navigateur et observez le déplacement du focus.

Exemple HTML + CSS

<a href="#contenu" class="skip-link">Aller directement au contenu</a>

<nav>
  <a href="index.html">Accueil</a>
  <a href="cours.html">Cours</a>
</nav>

<main id="contenu">
  <h1>Mon cours</h1>
</main>
.skip-link {
  position: absolute;
  left: -9999px;
}

.skip-link:focus {
  left: 1rem;
  top: 1rem;
  padding: 0.5rem 1rem;
}

Un lien d'évitement permet notamment de passer rapidement une navigation répétitive pour atteindre le contenu principal. citeturn0search2

7. Lisibilité avec CSS

L'accessibilité ne concerne pas uniquement HTML. Le CSS doit également conserver une bonne lisibilité et un focus visible.

body {
  font-family: Arial, sans-serif;
  line-height: 1.6;
}

button:focus-visible,
a:focus-visible,
input:focus-visible {
  outline: 3px solid currentColor;
  outline-offset: 3px;
}

8. JavaScript et accessibilité

JavaScript doit améliorer l'expérience sans supprimer les comportements natifs. Pour un bouton, utilisez un vrai <button> et ajoutez l'événement avec JavaScript.

HTML + JavaScript

<button id="messageBtn" type="button">
  Afficher le message
</button>

<p id="message"></p>

<script>
  const bouton = document.getElementById("messageBtn");
  const message = document.getElementById("message");

  bouton.addEventListener("click", function () {
    message.textContent = "Bienvenue dans le cours Frontend !";
  });
</script>

Le principe important est de conserver une structure HTML correcte avant d'ajouter le comportement JavaScript.

9. Qu'est-ce que le SEO ?

Le SEO, ou optimisation pour les moteurs de recherche, consiste notamment à aider les moteurs à comprendre le contenu et la structure d'une page.

Un bon HTML sémantique peut aider à la fois l'accessibilité et la compréhension du contenu par les moteurs de recherche. citeturn0search1turn0search3

10. Le <title> et la meta description

Le document HTML possède des informations importantes dans <head>.

<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta
    name="description"
    content="Cours Frontend pour apprendre HTML, CSS et JavaScript."
  >
  <title>Cours Frontend — GOMA PRO Devs</title>
</head>

11. Les titres h1, h2 et h3

Les titres doivent représenter la hiérarchie du contenu. En général, une page possède un titre principal h1, puis des sections avec h2 et des sous-sections avec h3.

<h1>Formation Frontend</h1>

<h2>HTML</h2>
<p>Structure de la page.</p>

<h2>CSS</h2>
<h3>Mise en page</h3>
<p>Flexbox et Grid.</p>

12. Les liens doivent être explicites

Évitez les liens vagues comme « Cliquez ici ». Préférez un texte qui indique clairement la destination.

<!-- Peu explicite -->
<a href="cours.html">Cliquez ici</a>

<!-- Plus explicite -->
<a href="cours.html">Consulter le cours Frontend</a>

Des intitulés compréhensibles hors contexte sont plus utiles aux utilisateurs et aux technologies d'assistance. citeturn0search0turn0search2

13. Mini-projet : rendre une page accessible et mieux structurée

Voici une petite page complète à améliorer progressivement.

HTML

<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <meta name="description" content="Présentation d'une formation Frontend.">
  <title>Formation Frontend</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
  <a href="#contenu" class="skip-link">Aller au contenu</a>

  <header>
    <h1>Formation Frontend</h1>
  </header>

  <nav aria-label="Navigation principale">
    <a href="index.html">Accueil</a>
    <a href="cours.html">Cours Frontend</a>
  </nav>

  <main id="contenu">
    <section>
      <h2>Apprendre le développement web</h2>
      <p>HTML, CSS et JavaScript progressivement.</p>

      <figure>
        <img src="frontend.jpg" alt="Étudiant travaillant sur une interface web">
        <figcaption>Travail pratique de développement web.</figcaption>
      </figure>

      <form>
        <label for="nom">Nom</label>
        <input id="nom" name="nom" type="text" required>

        <button type="submit">S'inscrire</button>
      </form>
    </section>
  </main>

  <footer>
    <p>GOMA PRO Devs</p>
  </footer>
</body>
</html>

CSS

body {
  max-width: 900px;

  line-height: 1.6;
}

  max-width: 100%;
  height: auto;
}

.skip-link {
  position: absolute;
  left: -9999px;
}

.skip-link:focus {
  left: 1rem;
  top: 1rem;
  padding: 0.5rem;
  background: white;
}

input,
button {
  font: inherit;
  padding: 0.6rem;
}

button:focus-visible,
a:focus-visible,

  outline: 3px solid currentColor;
  outline-offset: 3px;
}

14. Méthode de vérification

  1. Ouvrir la page dans le navigateur.
  2. Utiliser uniquement la touche Tab pour parcourir les liens, champs et boutons.
  3. Vérifier que le focus est visible.
  4. Vérifier que chaque image informative possède un alt.
  5. Vérifier que chaque champ possède un label.
  6. Vérifier la présence d'un titre de page et d'une description pertinente.
  7. Vérifier que les titres suivent une hiérarchie logique.

15. TP

  1. Créer une page HTML avec header, nav, main, section et footer.
  2. Ajouter une image avec un alt pertinent.
  3. Créer un formulaire avec deux champs et des label correctement associés.
  4. Ajouter un bouton HTML réel et vérifier son fonctionnement au clavier.
  5. Ajouter un title et une meta description.
  6. Organiser le contenu avec h1, h2 et éventuellement h3.
  7. Tester la page uniquement avec le clavier.

Résumé

  • Accessibilité = rendre le site utilisable par le plus grand nombre.
  • HTML sémantique = choisir l'élément correspondant à son rôle.
  • alt = texte alternatif pour les images informatives.
  • label = étiquette claire pour les champs de formulaire.
  • Clavier = un bon moyen de vérifier la navigation et le focus.
  • SEO = améliorer la compréhension et la visibilité du contenu.
  • Une bonne structure HTML aide à la fois l'accessibilité et le SEO.
