HTML : construire une page web

HTML décrit la structure et le sens du contenu d'une page. CSS s'occupe de la présentation et JavaScript du comportement.

1. Structure minimale

<!doctype html>
<html lang="fr">
<head>
  <meta charset="utf-8">
  <title>Ma première page</title>
</head>
<body>
  <h1>Bonjour GOMA PRO Devs</h1>
  <p>Je commence le développement web.</p>
</body>
</html>

2. Balises essentielles

  • h1 à h6 : titres.
  • p : paragraphe.
  • a : lien.
  • img : image avec attribut alt.
  • ul/ol/li : listes.
  • header, nav, main, section, footer : structure sémantique.

3. Formulaire

<form>
  <label for="nom">Nom</label>
  <input id="nom" name="nom" type="text" required>
  <button type="submit">Envoyer</button>
</form>

Travaux pratiques

  1. Créer une page de présentation personnelle.
  2. Ajouter une navigation vers trois sections.
  3. Créer un formulaire avec nom, email et message.
  4. Utiliser des balises sémantiques.
