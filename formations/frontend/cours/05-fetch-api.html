Asynchronisme, Fetch et JSON

Les applications web communiquent souvent avec un serveur sans recharger toute la page.

Promise et async/await

async function chargerUtilisateurs() {
  try {
    const reponse = await fetch("https://example.com/api/users");
    if (!reponse.ok) throw new Error("Réponse HTTP invalide");
    const utilisateurs = await reponse.json();
    console.log(utilisateurs);
  } catch (erreur) {
    console.error(erreur);
  }
}

JSON

JSON représente des données structurées avec des objets et des tableaux. Le navigateur peut convertir une réponse JSON en objet JavaScript avec response.json().

Sécurité et robustesse

  • Vérifier les erreurs réseau et HTTP.
  • Ne jamais faire confiance aveuglément aux données reçues.
  • Ne pas placer de secrets dans le JavaScript envoyé au navigateur.
