WEB FRONTEND · CHAPITRE 05

Fetch, JSON et API

Dans le chapitre précédent, nous avons appris à sélectionner des éléments HTML, modifier leur contenu et réagir aux événements. Maintenant, nous allons apprendre à récupérer des données et à les afficher directement dans la page.

1. Objectif du chapitre

  • comprendre ce qu'est Fetch ;
  • comprendre le format JSON ;
  • utiliser async et await ;
  • vérifier response.ok ;
  • convertir une réponse avec response.json() ;
  • afficher les données dans le HTML avec le DOM ;
  • afficher un état de chargement et une erreur dans la page.

2. Rappel : JavaScript doit interagir avec le HTML

Dans notre progression, console.log() sert surtout au débogage. Le résultat principal doit être visible par l'utilisateur dans la page grâce au DOM. Nous allons donc travailler avec textContent, createElement() et appendChild().

3. Première étape : comprendre les données

const utilisateur = {
  nom: "Aline",
  metier: "Développeuse Frontend",
  ville: "Goma"
};

alert(utilisateur.nom);

Avec alert(), nous vérifions immédiatement qu'une donnée est accessible. Ensuite, nous allons apprendre à afficher cette donnée dans un élément HTML.

4. Afficher une donnée dans le HTML

HTML :

<h2 id="resultat">Résultat</h2>

JavaScript :

const utilisateur = {
  nom: "Aline",
  metier: "Développeuse Frontend"
};

const resultat = document.getElementById("resultat");
resultat.textContent = utilisateur.nom;

Cette fois, le résultat apparaît directement dans la page. C'est le type d'interaction DOM que nous voulons maîtriser avant de travailler avec des données réseau.

5. Qu'est-ce que JSON ?

JSON signifie JavaScript Object Notation. C'est un format texte très utilisé pour représenter et échanger des données structurées entre applications.

{
  "nom": "Aline",
  "metier": "Développeuse Frontend",
  "ville": "Goma"
}

Un fichier JSON peut contenir un objet ou un tableau d'objets. JavaScript peut ensuite analyser cette réponse avec response.json().

6. Qu'est-ce que Fetch ?

fetch() permet à JavaScript d'effectuer une requête pour récupérer une ressource. Il retourne une Promise qui sera traitée lorsque la réponse arrivera.

fetch("adresse-de-la-ressource")
  .then(response => response.json())
  .then(data => {
    // utiliser les données
  });

Pour les débutants, nous allons utiliser une autre écriture plus lisible : async/await.

7. Comprendre async et await

async function chargerDonnees() {
  const response = await fetch("./data/utilisateurs.json");
  const donnees = await response.json();

  alert(donnees[0].nom);
}

async indique que la fonction travaille avec des opérations asynchrones. await permet d'attendre le résultat d'une Promise avant de continuer.

8. Vérifier response.ok

Il ne suffit pas d'appeler fetch(). Une réponse HTTP comme 404 peut quand même produire un objet Response. Nous devons donc vérifier response.ok avant de traiter les données.

const response = await fetch("./data/utilisateurs.json");

if (!response.ok) {
  throw new Error("Impossible de charger les données");
}

9. Afficher les données dans le DOM

Notre HTML :

<div id="message">Chargement...</div>
<div id="liste-utilisateurs"></div>

Notre JavaScript :

async function chargerUtilisateurs() {
  const message = document.getElementById("message");
  const liste = document.getElementById("liste-utilisateurs");

  try {
    const response = await fetch("./data/utilisateurs.json");

    if (!response.ok) {
      throw new Error("Erreur HTTP : " + response.status);
    }

    const utilisateurs = await response.json();

    message.textContent = "Données chargées avec succès.";

    utilisateurs.forEach(utilisateur => {
      const article = document.createElement("article");
      const titre = document.createElement("h3");
      const metier = document.createElement("p");
      const ville = document.createElement("p");

      titre.textContent = utilisateur.nom;
      metier.textContent = "Métier : " + utilisateur.metier;
      ville.textContent = "Ville : " + utilisateur.ville;

      article.appendChild(titre);
      article.appendChild(metier);
      article.appendChild(ville);

      liste.appendChild(article);
    });
  } catch (erreur) {
    message.textContent = "Impossible de charger les données.";
  }
}

chargerUtilisateurs();

Nous ne mettons pas console.log() pour montrer le résultat principal. Nous créons réellement des éléments HTML avec le DOM et nous y plaçons les données.

10. Le rôle de createElement()

document.createElement("article") crée un nouvel élément HTML en JavaScript. Ensuite, appendChild() permet de l'ajouter à un autre élément.

const carte = document.createElement("div");
carte.textContent = "Bonjour depuis JavaScript";

const zone = document.getElementById("liste-utilisateurs");
zone.appendChild(carte);

11. L'état de chargement

Une requête réseau peut prendre du temps. Il est donc préférable d'informer l'utilisateur.

message.textContent = "Chargement des utilisateurs...";

Puis, lorsque les données sont reçues :

message.textContent = "Utilisateurs chargés.";

12. Afficher une erreur dans le HTML

try {
  // chargement des données
} catch (erreur) {
  message.textContent = "Une erreur est survenue.";
}

L'utilisateur doit voir un message compréhensible. Les détails techniques peuvent être utilisés par le développeur pendant le débogage, mais ils ne doivent pas remplacer le message visible dans l'interface.

13. Exemple complet : HTML + JavaScript

<!doctype html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <title>Utilisateurs</title>
</head>
<body>
  <h1>Liste des utilisateurs</h1>

  <p id="message">Chargement...</p>
  <section id="liste-utilisateurs"></section>

  <script>
    async function chargerUtilisateurs() {
      const message = document.getElementById("message");
      const liste = document.getElementById("liste-utilisateurs");

      try {
        const response = await fetch("./data/utilisateurs.json");

        if (!response.ok) {
          throw new Error("Erreur HTTP : " + response.status);
        }

        const utilisateurs = await response.json();
        message.textContent = "Données chargées.";

        utilisateurs.forEach(utilisateur => {
          const article = document.createElement("article");
          article.textContent =
            utilisateur.nom + " — " +
            utilisateur.metier + " — " +
            utilisateur.ville;

          liste.appendChild(article);
        });
      } catch (erreur) {
        message.textContent = "Impossible de charger les utilisateurs.";
      }
    }

    chargerUtilisateurs();
  </script>
</body>
</html>

  4. Utilise async/await.
  5. Vérifie response.ok.
  6. Transforme la réponse avec response.json().
  7. Crée une carte HTML pour chaque utilisateur avec createElement().
  8. Affiche les cartes dans le DOM.
  9. Affiche un message pendant le chargement.
  10. Affiche un message visible en cas d'erreur.

17. Résumé

  • fetch() récupère une ressource.
  • async/await facilite la lecture du code asynchrone.
  • response.ok permet de vérifier le succès HTTP.
  • response.json() transforme la réponse JSON en données JavaScript.
  • Le DOM permet d'afficher les données dans le HTML.
  • createElement() crée dynamiquement des éléments.
  • Les états de chargement et d'erreur doivent être visibles dans l'interface.
