DOM et événements

Le DOM représente la page HTML sous forme d'objets que JavaScript peut lire et modifier.

Sélectionner et modifier

const titre = document.querySelector("h1");
titre.textContent = "Bienvenue !";

document.querySelector(".message").classList.add("active");

Événements

const bouton = document.querySelector("button");

bouton.addEventListener("click", () => {
  document.querySelector("#resultat").textContent = "Bouton cliqué";
});

Formulaires

Pour intercepter un formulaire, écoutez l'événement submit et utilisez event.preventDefault() lorsque vous ne voulez pas que le navigateur recharge immédiatement la page.
