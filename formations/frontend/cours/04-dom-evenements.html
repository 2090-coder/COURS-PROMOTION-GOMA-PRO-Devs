WEB FRONTEND · CHAPITRE 04

DOM et événements

Après avoir appris les bases de JavaScript, nous allons maintenant faire communiquer JavaScript avec le HTML. C'est ici que la page devient interactive.

1. Qu'est-ce que le DOM ?

Le DOM (Document Object Model) représente le document HTML sous forme d'objets. JavaScript peut sélectionner ces objets, lire leurs informations et les modifier.

HTML → DOM → JavaScript → modification visible dans la page

2. Premier résultat visible : alert()

Avant de manipuler le DOM, on peut afficher un message à l'utilisateur avec alert().

alert("Bienvenue dans JavaScript !");

const nom = "Salomon";
alert("Bonjour " + nom);

alert() est utile pour les premiers exercices et pour comprendre qu'un programme JavaScript peut produire un résultat visible.

3. Sélectionner un élément HTML

<h1 id="titre">Ancien titre</h1>

const titre = document.getElementById("titre");

alert(titre.textContent);

On peut aussi utiliser querySelector(), qui sélectionne le premier élément correspondant au sélecteur fourni. citeturn0search7

const titre = document.querySelector("#titre");
const bouton = document.querySelector("button");

4. Modifier le HTML avec JavaScript

<h1 id="titre">Bonjour</h1>

const titre = document.querySelector("#titre");
titre.textContent = "Bienvenue sur mon site !";

Ici, JavaScript ne se contente plus d'afficher une information : il modifie réellement le contenu de la page.

5. Modifier une classe CSS

const message = document.querySelector(".message");
message.classList.add("active");
message.classList.remove("cache");

JavaScript peut donc modifier l'apparence d'une interface en ajoutant ou supprimant des classes CSS.

6. Comprendre les événements

Un événement est une action ou un changement détecté par le navigateur : clic, saisie au clavier, déplacement de souris, soumission d'un formulaire, chargement de la page, etc. citeturn0search0turn0search2

Le principe est :

UTILISATEUR
    ↓
ÉVÉNEMENT
    ↓
JAVASCRIPT
    ↓
ACTION SUR LE DOM

7. Premier bouton interactif

<button id="btn">Cliquez-moi</button>
<p id="resultat"></p>

const bouton = document.querySelector("#btn");
const resultat = document.querySelector("#resultat");

bouton.addEventListener("click", function() {
  resultat.textContent = "Vous avez cliqué sur le bouton !";
});

addEventListener() est la méthode recommandée pour enregistrer un gestionnaire d'événement. citeturn0search3

8. Utiliser alert() avec un événement

const bouton = document.querySelector("#btn");

bouton.addEventListener("click", function() {
  alert("Le bouton a été cliqué !");
});

Cet exercice fait le lien entre ce que nous avons appris au chapitre précédent et le DOM.

9. Lire la valeur d'un champ HTML

<input id="nom" type="text" placeholder="Votre nom">
<button id="valider">Valider</button>

const champ = document.querySelector("#nom");
const valider = document.querySelector("#valider");

valider.addEventListener("click", function() {
  alert("Bonjour " + champ.value);
});

10. Événement input

<input id="nom" type="text">
<p id="affichage"></p>

const champ = document.querySelector("#nom");
const affichage = document.querySelector("#affichage");

champ.addEventListener("input", function() {
  affichage.textContent = champ.value;
});

Chaque modification du champ peut maintenant être répercutée directement dans la page.

11. Premier compteur

<button id="plus">+1</button>
<p id="compteur">0</p>

let nombre = 0;
const plus = document.querySelector("#plus");
const compteur = document.querySelector("#compteur");

plus.addEventListener("click", function() {
  nombre = nombre + 1;
  compteur.textContent = nombre;
});

12. Les formulaires

Un formulaire déclenche notamment l'événement submit. Pour traiter les données avec JavaScript sans recharger immédiatement la page, on peut utiliser event.preventDefault().

const formulaire = document.querySelector("#formulaire");

formulaire.addEventListener("submit", function(event) {
  event.preventDefault();
  alert("Formulaire reçu !");
});

Résumé

  • alert() permet d'obtenir un premier résultat visible.
  • Le DOM représente la page HTML sous forme d'objets.
  • getElementById() et querySelector() permettent de sélectionner des éléments.
  • textContent permet de modifier un texte.
  • classList permet de modifier les classes CSS.
  • Les événements permettent de réagir aux actions de l'utilisateur.
  • addEventListener() permet d'attacher une action à un événement.
  • value permet de lire la valeur d'un champ.
  • preventDefault() permet notamment de contrôler le comportement par défaut d'un formulaire.
