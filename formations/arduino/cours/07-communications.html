Arduino 07 — UART, I²C et SPI

UART / Serial

UART est une communication série asynchrone. Avec Arduino, Serial sert souvent à communiquer avec un PC ou un autre module série.

void setup(){
  Serial.begin(115200);
}
void loop(){
  Serial.println("Bonjour GOMA PRO Devs");
  delay(1000);
}

I²C

I²C utilise généralement deux lignes : SDA pour les données et SCL pour l'horloge. Plusieurs périphériques peuvent partager le bus grâce à leurs adresses.

#include <Wire.h>

void setup(){
  Wire.begin();
}

void loop(){
  Wire.beginTransmission(0x3C);
  Wire.write(0x00);
  Wire.endTransmission();
  delay(1000);
}

SPI

SPI utilise typiquement SCK, MOSI, MISO et une sélection de périphérique CS/SS. Il est souvent utilisé pour écrans, cartes mémoire et capteurs.

Comparer

UART : simple et point à point. I²C : plusieurs périphériques avec deux lignes. SPI : rapide et efficace, mais utilise davantage de lignes.
