Arduino 07 — Moniteur série et communications

Objectif : apprendre à observer un programme, diagnostiquer un montage et faire communiquer Arduino avec des périphériques.

1. Moniteur série

Serial permet d'envoyer des informations vers l'ordinateur. C'est un outil essentiel de débogage.

void setup(){ Serial.begin(9600); }
void loop(){
  int valeur = analogRead(A0);
  Serial.print("A0 = ");
  Serial.println(valeur);
  delay(500);
}

print() reste sur la ligne ; println() ajoute un retour. Le débit doit être identique des deux côtés, par exemple 9600 bauds.

2. UART : le principe

UART est une communication série asynchrone. Une liaison typique utilise TX pour transmettre, RX pour recevoir et GND comme référence.

  • TX d'un équipement → RX de l'autre.
  • RX → TX.
  • GND → GND.
  • Vérifier impérativement les niveaux logiques avant connexion.

3. Tester un module série

void loop(){
  if (Serial.available()) {
    char c = Serial.read();
    Serial.print("Reçu : ");
    Serial.println(c);
  }
}

On peut ainsi comprendre le flux caractère par caractère.

4. I²C

I²C utilise SDA pour les données et SCL pour l'horloge. Plusieurs périphériques peuvent partager les lignes en utilisant des adresses différentes.

#include <Wire.h>
void setup(){
  Wire.begin();
  Serial.begin(9600);
}
void loop(){}

Un scanner I²C est un excellent exercice pour découvrir les adresses présentes sur un bus.

5. SPI

SPI utilise généralement SCK, MOSI, MISO et CS/SS. Contrairement à I²C, chaque périphérique utilise généralement une sélection CS distincte.

À retenir

  • Le moniteur série sert à afficher et diagnostiquer.
  • UART est point à point dans son usage courant.
  • I²C partage SDA/SCL grâce aux adresses.
  • SPI utilise une sélection de périphérique et est adapté à de nombreux périphériques rapides.
