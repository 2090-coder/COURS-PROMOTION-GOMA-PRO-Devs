Arduino 07 — Moniteur série et communications

Nous apprenons à observer un programme, envoyer des données et découvrir les principaux bus de communication.

1. Le moniteur série

void setup() {
  Serial.begin(9600);
}
void loop() {
  Serial.println("Bonjour Arduino");
  delay(1000);
}

Le moniteur série permet d'observer des valeurs et des messages envoyés par la carte.

2. Afficher des mesures

int valeur = analogRead(A0);
Serial.print("Valeur = ");
Serial.println(valeur);

print() continue sur la même ligne ; println() ajoute un retour à la ligne.

3. UART / Serial

La communication série asynchrone permet à deux équipements compatibles d'échanger des données. Avec Arduino, Serial est souvent utilisé avec un ordinateur ou un module série.

4. I²C

I²C utilise généralement SDA pour les données et SCL pour l'horloge. Plusieurs périphériques peuvent partager le même bus grâce à leurs adresses.

#include <Wire.h>

void setup() {
  Wire.begin();
}
void loop() {
}

5. SPI

SPI utilise typiquement SCK, MOSI, MISO et une ligne de sélection du périphérique. Il est courant pour certains écrans, mémoires et capteurs.

6. Quand utiliser quoi ?

  • Serial/UART : simple échange série.
  • I²C : plusieurs périphériques avec peu de lignes.
  • SPI : communication rapide avec plusieurs périphériques selon la configuration.

7. TP

Résumé

  • Serial.begin() initialise la communication série.
  • Serial.print() et println() affichent des données.
  • UART/Serial, I²C et SPI sont trois méthodes de communication différentes.
  • Le choix dépend du périphérique et des besoins du projet.
