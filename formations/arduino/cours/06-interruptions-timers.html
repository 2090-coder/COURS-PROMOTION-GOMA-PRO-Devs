Arduino 06 — Interruptions et timers

Pourquoi une interruption ?

Une interruption permet au microcontrôleur de réagir rapidement à un événement sans attendre la fin d'une boucle longue.

Interruption externe

volatile bool evenement = false;

void ISR_bouton() {
  evenement = true;
}

void setup() {
  pinMode(2, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(2), ISR_bouton, FALLING);
}

void loop() {
  if (evenement) {
    evenement = false;
    // traiter l'événement
  }
}

Une routine d'interruption doit rester courte. Les variables partagées avec une ISR sont souvent déclarées volatile.

Timers

Les timers servent à mesurer des intervalles, produire des signaux ou déclencher périodiquement une action. Les bibliothèques et possibilités dépendent du microcontrôleur.

unsigned long precedent = 0;
const unsigned long periode = 1000;

void loop() {
  unsigned long maintenant = millis();
  if (maintenant - precedent >= periode) {
    precedent = maintenant;
    // tâche périodique
  }
}

  2. Afficher le compteur sans bloquer avec de longs delay().
  3. Ajouter une tâche périodique toutes les secondes avec millis().
  4. Comparer cette approche avec une interruption.
