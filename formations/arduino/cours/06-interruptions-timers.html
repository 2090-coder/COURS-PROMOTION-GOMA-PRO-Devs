Arduino 06 — Entrées, analogique, PWM et capteurs

Nous passons maintenant de la commande des sorties à la lecture du monde extérieur : boutons, potentiomètre et premiers capteurs.

1. Entrée ou sortie ?

  • Entrée : Arduino reçoit une information.
  • Sortie : Arduino commande un élément.

Exemple : bouton → Arduino = entrée ; Arduino → LED = sortie.

2. Lire un bouton avec digitalRead()

int bouton = 2;
int led = 13;

void setup() {
  pinMode(bouton, INPUT_PULLUP);
  pinMode(led, OUTPUT);
}

void loop() {
  int etat = digitalRead(bouton);

  if (etat == LOW) {
    digitalWrite(led, HIGH);
  } else {
    digitalWrite(led, LOW);
  }
}

Avec INPUT_PULLUP, le bouton est généralement lu à LOW lorsqu'il est appuyé dans ce montage.

3. Comprendre le bouton

Il faut comprendre le câblage avant de programmer : le bouton relie ou sépare deux points électriques. La résistance de rappel interne permet d'obtenir un état logique défini.

4. Anti-rebond : première idée

Un bouton mécanique peut produire plusieurs changements rapides lors d'un seul appui. On appelle cela le rebond. Dans un premier temps, on peut utiliser une petite attente après la détection ; plus tard, nous apprendrons des méthodes plus robustes.

5. Lire une entrée analogique

int valeur = analogRead(A0);
Serial.println(valeur);

Une entrée analogique permet de mesurer une grandeur électrique dans la plage supportée par la carte. La résolution et la plage dépendent du modèle.

6. Potentiomètre

Le potentiomètre est un excellent premier composant pour comprendre l'analogique : en tournant son axe, la tension envoyée à l'entrée analogique varie.

int potentiometre = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int valeur = analogRead(potentiometre);
  Serial.println(valeur);
  delay(100);
}

7. PWM et luminosité d'une LED

Le PWM permet de produire un signal périodique dont le rapport cyclique peut être contrôlé. Sur les broches compatibles, analogWrite() permet notamment de régler la puissance moyenne appliquée à une LED pour modifier sa luminosité.

int led = 9;

void setup() {
  pinMode(led, OUTPUT);
}

void loop() {
  analogWrite(led, 128);
}

8. Potentiomètre → LED

int pot = A0;
int led = 9;

void setup() {
  pinMode(led, OUTPUT);
}

void loop() {
  int valeur = analogRead(pot);
  int luminosite = map(valeur, 0, 1023, 0, 255);
  analogWrite(led, luminosite);
}

La fonction map() transforme une valeur d'une plage vers une autre. Les plages exactes d'analogRead() et de PWM dépendent de la carte.

9. Premiers capteurs

Une fois le principe compris avec un potentiomètre, on peut appliquer la même logique à un capteur de lumière, de température ou à un autre capteur adapté à la carte. On commence toujours par lire et afficher la valeur avant de commander une sortie.

10. TP progressifs

  1. Faire allumer une LED quand un bouton est appuyé.
  2. Afficher l'état du bouton dans le moniteur série.
  3. Lire un potentiomètre et afficher sa valeur.
  4. Commander la luminosité d'une LED avec le potentiomètre.
  5. Ajouter un seuil : si la valeur dépasse un niveau choisi, allumer une LED.
  6. Remplacer progressivement le potentiomètre par un capteur analogique adapté.

Résumé

  • digitalRead() lit une entrée numérique.
  • analogRead() lit une entrée analogique.
  • INPUT_PULLUP utilise une résistance de rappel interne.
  • Un potentiomètre permet de tester facilement l'analogique.
  • analogWrite() permet d'utiliser le PWM sur les broches compatibles.
  • map() convertit une valeur d'une plage vers une autre.
  • Les capteurs fournissent des informations qu'Arduino peut traiter.
