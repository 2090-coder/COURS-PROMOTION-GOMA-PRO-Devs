Arduino 04 — Conditions et boucles

Après les variables, nous apprenons à faire prendre des décisions au programme puis à répéter des instructions.

1. La condition if

int temperature = 30;
if (temperature > 25) {
  // action
}

Le bloc est exécuté uniquement si la condition est vraie.

2. Comparer des valeurs

  • == égal
  • != différent
  • > supérieur
  • < inférieur
  • >= supérieur ou égal
  • <= inférieur ou égal

Attention : = affecte une valeur, alors que == compare.

3. if / else / else if

if (valeur >= 80) {
  // très bon
} else if (valeur >= 50) {
  // moyen
} else {
  // insuffisant
}

4. Opérateurs logiques

if (temperature > 20 && temperature < 30) {
  // entre 20 et 30
}

&& = ET, || = OU, ! = NON.

5. Première boucle for

for (int i = 0; i < 5; i++) {
  Serial.println(i);
}

La boucle répète le bloc plusieurs fois. Elle possède une initialisation, une condition et une évolution.

6. while et do...while

int compteur = 0;
while (compteur < 5) {
  Serial.println(compteur);
  compteur++;
}
int compteur = 0;
do {
  Serial.println(compteur);
  compteur++;
} while (compteur < 5);

do...while exécute le bloc au moins une fois avant de tester la condition.

7. Exemple : faire clignoter une LED cinq fois

int led = 13;
void setup() { pinMode(led, OUTPUT); }
void loop() {
  for (int i = 0; i < 5; i++) {
    digitalWrite(led, HIGH);
    delay(300);
    digitalWrite(led, LOW);
    delay(300);
  }
  delay(1000);
}

8. TP progressifs

  1. Allumer une LED si une variable vaut 1, sinon l'éteindre.
  2. Afficher 0 à 9 avec for.
  3. Faire clignoter une LED exactement 10 fois.
  4. Reprendre le chainillard de 5 LEDs du chapitre 03 et réfléchir à la façon dont une boucle pourrait éviter les répétitions.

Résumé

  • if permet de décider.
  • else définit l'autre cas.
  • else if permet plusieurs cas.
  • &&, || et ! combinent les conditions.
  • for, while et do...while répètent des instructions.
