Arduino 04 — Conditions et boucles

Maintenant que nous savons utiliser les variables, nous allons apprendre à faire prendre des décisions au programme et à répéter des instructions.

1. Pourquoi avons-nous besoin de conditions ?

Jusqu'ici, notre programme exécutait les instructions dans un ordre déterminé. Mais un système réel doit souvent répondre à une situation.

Exemple : si un bouton est appuyé, allumer la LED ; sinon, éteindre la LED.

Le mot important est si. En programmation, on utilise principalement if et else.

2. La condition if

if (condition) {
  // instructions exécutées si la condition est vraie
}

La partie entre parenthèses doit produire une réponse logique : vraie ou fausse.

int temperature = 30;

if (temperature > 25) {
  // cette partie sera exécutée
}

3. Les opérateurs de comparaison

  • == : égal à
  • != : différent de
  • > : supérieur à
  • < : inférieur à
  • >= : supérieur ou égal à
  • <= : inférieur ou égal à
Attention : = sert à affecter une valeur, tandis que == sert à comparer deux valeurs.

4. if et else

int temperature = 20;

if (temperature > 25) {
  // température élevée
} else {
  // température normale
}

Une seule des deux branches est exécutée.

5. Premier exercice avec une LED

Nous allons utiliser une variable pour le numéro de la LED et une autre pour décider si elle doit être allumée.

int led = 13;
int allumer = 1;

void setup() {
  pinMode(led, OUTPUT);
}

void loop() {
  if (allumer == 1) {
    digitalWrite(led, HIGH);
  } else {
    digitalWrite(led, LOW);
  }
}

Modifie ensuite la valeur de allumer pour observer le comportement.

6. Plusieurs conditions avec else if

int valeur = 75;

if (valeur >= 80) {
  // très bon
} else if (valeur >= 50) {
  // moyen
} else {
  // insuffisant
}

Les conditions sont évaluées dans l'ordre. Dès qu'une condition est vraie, sa branche est exécutée.

7. Opérateurs logiques

  • && : ET
  • || : OU
  • ! : NON
if (temperature > 20 && temperature < 30) {
  // température comprise entre 20 et 30
}

8. Pourquoi avons-nous besoin des boucles ?

Une boucle permet de répéter une instruction ou un groupe d'instructions sans recopier le même code plusieurs fois.

Arduino possède notamment les structures for, while et do...while. Les exemples officiels Arduino comprennent également des exemples dédiés aux boucles et aux structures de contrôle. citeturn0search1turn0search0

9. La boucle for

for (int i = 0; i < 5; i++) {
  Serial.println(i);
}

Cette boucle répète le bloc pour les valeurs 0, 1, 2, 3 et 4.

Initialisation : int i = 0
Condition : i < 5
Évolution : i++

10. Faire clignoter une LED plusieurs fois

int led = 13;

void setup() {
  pinMode(led, OUTPUT);
}

void loop() {
  for (int i = 0; i < 5; i++) {
    digitalWrite(led, HIGH);
    delay(300);
    digitalWrite(led, LOW);
    delay(300);
  }

  delay(1000);
}

Ici, le clignotement est exécuté cinq fois avant une pause d'une seconde.

11. La boucle while

int compteur = 0;

while (compteur < 5) {
  Serial.println(compteur);
  compteur++;
}

while répète les instructions tant que la condition reste vraie.

Attention : il faut faire évoluer la condition. Sinon, une boucle while peut ne jamais s'arrêter.

12. La boucle do...while

int compteur = 0;

do {
  Serial.println(compteur);
  compteur++;
} while (compteur < 5);

La différence importante est que le bloc do est exécuté au moins une fois avant de vérifier la condition.
