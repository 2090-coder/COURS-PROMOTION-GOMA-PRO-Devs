Arduino 20 — Projet final professionnel

1. Cahier des charges

Définir le problème, les entrées, sorties, contraintes, composants, alimentation, données et résultat attendu.

2. Projets proposés

  • Station environnementale : capteurs + OLED + RTC + SD.
  • Système de localisation : GPS + OLED + SD.
  • Contrôle d'accès pédagogique : RFID + OLED + servo.
  • Système d'alerte : capteur + GSM + journalisation.
  • Station de mesure optique : MAX30102 + OLED + stockage.

3. Intégration

L'étudiant doit construire le projet progressivement : tester chaque module, créer les fonctions, gérer les erreurs, puis réunir les sous-systèmes avec millis et les communications nécessaires.

4. Livrables

  1. Code source .ino.
  2. Résumé et documentation.
  3. Schéma de câblage.
  4. Liste des composants.
  5. Tests et résultats.
  6. Présentation orale.

Compétences finales

L'apprenant doit savoir partir d'une carte Arduino, choisir un composant, lire sa documentation, installer une bibliothèque, câbler un module, écrire et tester le code, communiquer avec des périphériques et construire un système embarqué documenté.
