Arduino 18 — Bibliothèques et intégration

1. Pourquoi une bibliothèque ?

Une bibliothèque réutilise du code déjà organisé pour un composant ou une fonctionnalité. Arduino fournit un gestionnaire de bibliothèques et une documentation dédiée.

2. Installer et utiliser

  1. Ouvrir le Library Manager.
  2. Rechercher la bibliothèque.
  3. Vérifier son auteur, sa compatibilité et ses exemples.
  4. Installer.
  5. Tester un exemple minimal.
  6. Inclure avec #include.

3. Intégration multi-modules

Nous combinons plusieurs bibliothèques : RTC + OLED + GPS, ou RFID + OLED, puis nous organisons le code en fonctions et sous-systèmes.

4. Créer sa propre bibliothèque

Découvrir la structure .h/.cpp, les classes, les dépendances, les exemples et les métadonnées.

TP

  1. Installer une bibliothèque.

  3. Créer une classe simple pour une LED.
  4. Transformer cette classe en bibliothèque.

Résumé

  • Une bibliothèque ajoute des fonctionnalités.
  • Le Library Manager simplifie l'installation.
  • Une bibliothèque personnelle doit être organisée et documentée.
