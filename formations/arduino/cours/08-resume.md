# Arduino 08 — Résumé

- Les tableaux regroupent plusieurs valeurs.
- Les chaînes représentent du texte.
- Les structures regroupent plusieurs informations liées.
- La portée détermine où une variable est accessible.
- La mémoire d'un microcontrôleur est limitée.
- Les pointeurs représentent des adresses mémoire.
- Les bibliothèques permettent de réutiliser du code existant.
