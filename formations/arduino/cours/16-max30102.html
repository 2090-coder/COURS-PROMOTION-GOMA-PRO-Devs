Arduino 16 — MAX30102 et capteurs biométriques

Objectif : comprendre l'acquisition optique, lire les données du MAX30102, observer le signal et découvrir les principes de filtrage et d'estimation du pouls.

Important : ce chapitre est éducatif. Les mesures d'un module de prototypage ne constituent pas un diagnostic médical et ne doivent pas servir à décider seul d'une conduite médicale.

1. Que mesure le MAX30102 ?

Le MAX30102 utilise des sources lumineuses et un photodétecteur pour observer des variations optiques liées au flux sanguin. Il fournit notamment des échantillons de signaux IR et rouge que le programme peut traiter.

2. Communication I²C

Le capteur communique généralement avec le microcontrôleur via I²C. On retrouve donc SDA, SCL, alimentation et masse. Le câblage exact dépend du breakout utilisé.

3. Bibliothèque

Plusieurs bibliothèques compatibles existent. Il faut choisir une bibliothèque adaptée au breakout et à l'exemple fourni par son fabricant.

4. Lecture de données : principe

#include <Wire.h>
// Ajouter ici la bibliothèque MAX30102 adaptée

void setup(){
  Serial.begin(115200);
  Wire.begin();
  // initialiser le capteur
}

void loop(){
  // lire un nouvel échantillon
  // afficher la valeur IR/rouge
  delay(20);
}

La structure est volontairement progressive : avant de calculer un BPM, il faut vérifier que le capteur communique et que les échantillons arrivent correctement.

5. Comprendre le signal

Un signal réel contient du bruit, des variations dues au mouvement, à la position du doigt et à la lumière ambiante. On peut étudier une moyenne glissante ou d'autres filtres simples avant de rechercher des pics.

// moyenne simple de N valeurs
moyenne = (x1 + x2 + x3 + x4) / 4.0;

6. Du signal au BPM

Une estimation de fréquence cardiaque repose conceptuellement sur la détection d'événements périodiques dans le signal et la mesure de l'intervalle entre eux. Pour une période T en secondes :

BPM ≈ 60 / T

Cette estimation doit être contrôlée et filtrée ; une valeur instantanée isolée peut être trompeuse.

7. MAX30102 + OLED

Une architecture pédagogique peut lire les échantillons, calculer une estimation puis afficher le signal ou une valeur sur OLED. On combine ainsi I²C, acquisition, traitement et interface utilisateur.

8. Ce qu'il faut tester

  1. Le capteur est-il détecté sur le bus ?
  2. Les échantillons changent-ils lorsque les conditions de mesure changent ?
  3. Le signal est-il suffisamment stable ?
  4. Le programme gère-t-il l'absence de données ?
  5. Le résultat est-il présenté comme une estimation et non comme un diagnostic ?

TP progressif

  1. Détecter le capteur.
  2. Lire les échantillons bruts.
  3. Afficher les valeurs dans le moniteur série.
  4. Observer l'effet du bruit et du mouvement.
  5. Appliquer une moyenne simple.
  6. Afficher une estimation pédagogique sur OLED.

À retenir

  • MAX30102 = capteur optique de signaux biométriques.
  • I²C assure généralement la communication.
  • Le traitement du signal est aussi important que la lecture.
  • Une mesure de prototype doit être interprétée avec prudence.
