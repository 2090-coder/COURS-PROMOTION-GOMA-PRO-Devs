# Arduino 09 — Résumé

- `millis()` permet de gérer le temps sans longs blocages.
- Les interruptions répondent à certains événements matériels.
- Les timers sont des ressources matérielles.
- Les registres permettent un contrôle plus bas niveau et dépendent de l'architecture.
- Les bibliothèques fournissent du code réutilisable.
- Le débogage consiste à observer, isoler, tester et corriger.
