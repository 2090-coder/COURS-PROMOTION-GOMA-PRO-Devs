Arduino 08 — Bibliothèques et architecture du code

Pourquoi créer une bibliothèque ?

Une bibliothèque regroupe du code réutilisable. Elle permet de séparer l'interface publique de l'implémentation et de rendre les projets plus propres.

Fichier d'en-tête

#ifndef LED_MANAGER_H
#define LED_MANAGER_H

class LedManager {
public:
  LedManager(int pin);
  void begin();
  void on();
  void off();
private:
  int _pin;
};

#endif

Implémentation

#include "LedManager.h"

LedManager::LedManager(int pin) : _pin(pin) {}
void LedManager::begin(){ pinMode(_pin, OUTPUT); }
void LedManager::on(){ digitalWrite(_pin, HIGH); }
void LedManager::off(){ digitalWrite(_pin, LOW); }

Utilisation

#include "LedManager.h"
LedManager led(13);
void setup(){ led.begin(); }
void loop(){ led.on(); delay(500); led.off(); delay(500); }

Bonnes pratiques

  • Nommer clairement les classes et fonctions.
  • Éviter les variables globales inutiles.
  • Documenter les paramètres.
  • Tester une bibliothèque avec un exemple minimal.
