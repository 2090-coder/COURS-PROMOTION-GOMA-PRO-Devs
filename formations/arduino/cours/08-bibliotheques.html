Arduino 08 — C/C++ avancé pour Arduino

Après les bases, nous approfondissons les outils du C/C++ utiles aux programmes embarqués.

1. Les tableaux

int leds[5] = {8, 9, 10, 11, 12};

for (int i = 0; i < 5; i++) {
  pinMode(leds[i], OUTPUT);
}

Un tableau permet de stocker plusieurs valeurs du même type sous un même nom.

2. Les chaînes de caractères

char message[] = "Arduino";
String nom = "GOMA PRO Devs";
Serial.println(nom);

On distingue les chaînes de caractères en tableau de char et la classe Arduino String.

3. Structures

struct Led {
  int broche;
  int temps;
};

Led led1 = {8, 300};

Une structure permet de regrouper plusieurs informations liées.

4. Portée des variables

int globale = 10;

void exemple() {
  int locale = 20;
}

Une variable globale et une variable locale n'ont pas la même portée. Il faut éviter les variables globales inutiles.

5. Mémoire et bonnes pratiques

Sur un microcontrôleur, la mémoire est limitée. Il faut donc éviter de créer inutilement de grandes données, choisir des types adaptés et organiser le code proprement.

6. Pointeurs : première découverte

int valeur = 10;
int *adresse = &valeur;

Un pointeur contient une adresse mémoire. Cette notion sera approfondie uniquement lorsque les bases précédentes sont maîtrisées.

7. Bibliothèques : utiliser du code réutilisable

#include <Wire.h>

Une bibliothèque fournit du code déjà organisé pour une fonctionnalité ou un composant. On apprend ici à l'utiliser ; la création de bibliothèques sera abordée dans les projets avancés.

8. TP

  1. Créer un tableau contenant les cinq broches du chainillard.
  2. Afficher les valeurs du tableau dans le moniteur série.
  3. Créer une structure décrivant une LED.
  4. Créer une petite fonction utilisant un tableau.
  5. Tester une bibliothèque Arduino officielle avec un composant adapté.

Résumé

  • Les tableaux regroupent plusieurs valeurs.
  • Les chaînes représentent du texte.
  • Les structures regroupent des informations différentes.
  • La portée détermine où une variable est accessible.
  • La mémoire d'un microcontrôleur doit être utilisée avec soin.
  • Les pointeurs représentent des adresses mémoire.
  • Les bibliothèques permettent de réutiliser du code.
