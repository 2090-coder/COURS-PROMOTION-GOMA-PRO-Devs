Arduino 08 — Tableaux, chaînes et structures

Après les communications, nous apprenons à organiser plusieurs données avant de travailler avec des mémoires et des modules spécialisés.

1. Tableaux

int leds[5] = {8, 9, 10, 11, 12};
for (int i = 0; i < 5; i++) {
  pinMode(leds[i], OUTPUT);
}

2. Chaînes de caractères

char message[] = "Arduino";
String nom = "GOMA PRO Devs";
Serial.println(nom);

On compare la chaîne en tableau de char et la classe String, en tenant compte de la mémoire disponible.

3. Structures

struct Capteur {
  int pin;
  float valeur;
};
Capteur c1 = {A0, 0};

4. Parcourir et traiter des données

Nous combinons tableaux, boucles et fonctions pour gérer plusieurs LEDs ou plusieurs mesures sans répéter le même code.

TP

  1. Créer un tableau de cinq LEDs.
  2. Afficher chaque position dans le moniteur série.
  3. Créer une structure décrivant un capteur.
  4. Créer une fonction qui affiche une liste de valeurs.

Résumé

  • Tableau = plusieurs valeurs du même type.
  • Chaîne = texte.
  • Structure = plusieurs informations regroupées.
  • Les données doivent être organisées avec la mémoire limitée du microcontrôleur à l'esprit.
