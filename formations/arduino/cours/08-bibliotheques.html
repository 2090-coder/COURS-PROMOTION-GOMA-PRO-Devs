Arduino 08 — Tableaux, chaînes et structures

Objectif : organiser proprement les données d'un programme embarqué et réutiliser les mêmes traitements sur plusieurs valeurs.

1. Pourquoi organiser les données ?

Un microcontrôleur travaille avec des ressources limitées. Les tableaux, chaînes et structures permettent de représenter plusieurs informations sans créer une multitude de variables isolées.

2. Tableaux

int valeurs[5] = {10,20,30,40,50};
for(int i=0;i<5;i++){
  Serial.println(valeurs[i]);
}

L'indice commence à 0. Le dernier élément d'un tableau de 5 cases est donc l'indice 4.

3. Tableaux de broches

const byte leds[] = {8,9,10};
const byte N = 3;
void setup(){
  for(byte i=0;i<N;i++) pinMode(leds[i],OUTPUT);
}

4. Chaînes de caractères

char message[] = "Arduino";
String nom = "GOMA PRO Devs";
Serial.println(message);
Serial.println(nom);

char[] est une chaîne C stockée dans un tableau. String est plus simple à manipuler mais il faut rester attentif à la RAM sur les petites cartes.

5. Structures

struct Capteur {
  const char* nom;
  byte pin;
  float valeur;
};
Capteur temperature = {"Temperature", A0, 0};

Une structure regroupe plusieurs champs qui décrivent le même objet.

6. Fonctions + données

void afficher(int tab[], byte taille){
  for(byte i=0;i<taille;i++) Serial.println(tab[i]);
}

Cette approche évite de répéter le même code et prépare à des programmes plus professionnels.

TP progressif

  1. Créer un tableau de cinq mesures.
  2. Calculer la somme et la moyenne.
  3. Créer un tableau de trois LEDs et les commander dans une boucle.
  4. Créer une chaîne de caractères et l'afficher.
  5. Créer une structure décrivant un capteur.
  6. Écrire une fonction qui affiche une liste de mesures.

À retenir

  • Tableau = plusieurs valeurs accessibles par indice.
  • Chaîne = représentation de texte.
  • Structure = plusieurs champs réunis dans un même objet logique.
  • Une bonne organisation simplifie les projets de capteurs et d'automatisation.
