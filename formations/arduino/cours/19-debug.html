Arduino 19 — Temps, interruptions et débogage

1. millis()

unsigned long precedent = 0;
const unsigned long periode = 1000;
if (millis() - precedent >= periode) {
  precedent = millis();
  // tâche
}

Apprendre à réaliser plusieurs tâches sans bloquer tout le programme avec de longs delay().

2. Interruptions

Une interruption permet de réagir rapidement à certains événements matériels. La disponibilité et la syntaxe dépendent de la carte.
