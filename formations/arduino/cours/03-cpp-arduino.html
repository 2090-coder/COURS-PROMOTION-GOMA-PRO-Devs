ARDUINO — CHAPITRE 03

Les variables et les types

Après avoir commandé directement les broches, nous apprenons maintenant à donner des noms aux valeurs et à choisir le type de donnée adapté.

1. Pourquoi apprendre les variables maintenant ?

Dans le chapitre 02, nous avons écrit directement les numéros des broches :

pinMode(13, OUTPUT);
pinMode(12, OUTPUT);

digitalWrite(13, HIGH);
delay(500);
digitalWrite(13, LOW);

digitalWrite(12, HIGH);
delay(500);
digitalWrite(12, LOW);

Le programme fonctionne. Mais si la LED 1 change de broche, nous devons retrouver tous les 13. Une variable permet de donner un nom à cette valeur.

2. Qu'est-ce qu'une variable ?

Une variable est une zone de mémoire associée à un nom et contenant une valeur. Cette valeur peut être utilisée et, selon le type de variable, modifiée pendant l'exécution du programme.

int led1 = 13;
int led2 = 12;

Ici, led1 représente la valeur 13 et led2 représente la valeur 12.

3. Anatomie d'une déclaration

int led1 = 13;
  • int : le type de la donnée.
  • led1 : le nom de la variable.
  • = : l'affectation.
  • 13 : la valeur initiale.
  • ; : la fin de l'instruction.

On peut ensuite utiliser le nom de la variable :

pinMode(led1, OUTPUT);
digitalWrite(led1, HIGH);

4. Les principaux types de variables utilisés avec Arduino

La référence officielle Arduino distingue les variables et constantes parmi les grandes parties du langage. Le choix du type dépend de la valeur à stocker et de la carte utilisée. citeturn1search1

5. Déclarer, initialiser et modifier

int compteur;
compteur = 0;
compteur = 10;
compteur = compteur + 1;

On peut aussi initialiser directement :

int compteur = 0;

Quelques raccourcis utiles :

compteur++;
compteur--;
compteur += 5;
compteur -= 2;

6. Constantes

Quand une valeur ne doit pas être modifiée par le programme, on peut utiliser const.

const int led1 = 13;
const int led2 = 12;

Pour les numéros de broches, cette pratique rend souvent le programme plus clair et évite de modifier accidentellement une configuration.

7. TP principal — Chainillard de 5 LEDs

Nous allons maintenant refaire l'idée du chapitre 02, mais avec des variables et 5 LEDs. Le comportement demandé est :

LED 1 → LED 2 → LED 3 → LED 4 → LED 5 → puis retour LED 5 → LED 4 → LED 3 → LED 2 → LED 1.

Chaque LED s'allume seule pendant un court instant, puis s'éteint avant que la suivante ne s'allume.

Objectif

  1. Déclarer cinq variables pour les broches.
  2. Configurer les cinq broches en sortie.
  3. Allumer les LEDs une par une dans l'ordre croissant.
  4. Éteindre chaque LED avant de passer à la suivante.
  5. Arrivé à la LED 5, redescendre dans l'ordre inverse.
  6. Répéter continuellement la séquence.
int led1 = 8;
int led2 = 9;
int led3 = 10;
int led4 = 11;
int led5 = 12;

void setup() {
  pinMode(led1, OUTPUT);
  pinMode(led2, OUTPUT);
  pinMode(led3, OUTPUT);
  pinMode(led4, OUTPUT);
  pinMode(led5, OUTPUT);
}

void loop() {
  digitalWrite(led1, HIGH);
  delay(300);
  digitalWrite(led1, LOW);

  digitalWrite(led2, HIGH);
  delay(300);
  digitalWrite(led2, LOW);

  digitalWrite(led3, HIGH);
  delay(300);
  digitalWrite(led3, LOW);

  digitalWrite(led4, HIGH);
  delay(300);
  digitalWrite(led4, LOW);

  digitalWrite(led5, HIGH);
  delay(300);
  digitalWrite(led5, LOW);

  digitalWrite(led4, HIGH);
  delay(300);
  digitalWrite(led4, LOW);

  digitalWrite(led3, HIGH);
  delay(300);
  digitalWrite(led3, LOW);

  digitalWrite(led2, HIGH);
  delay(300);
  digitalWrite(led2, LOW);

  digitalWrite(led1, HIGH);
  delay(300);
  digitalWrite(led1, LOW);
}

Cette première version est volontairement écrite étape par étape. Nous n'utilisons pas encore les boucles for : elles seront étudiées plus tard, afin de comprendre d'abord les variables et l'ordre d'exécution.

8. Comprendre le chainillard

Les variables ne font pas « fonctionner » les LEDs à elles seules. Elles donnent simplement des noms aux valeurs des broches. Les fonctions pinMode() et digitalWrite() continuent de commander réellement les sorties.

led1 → 8
led2 → 9
led3 → 10
led4 → 11
led5 → 12

Si nous changeons le câblage, nous pouvons modifier les valeurs au début du programme sans rechercher chaque numéro dans toutes les instructions.

9. Afficher une variable dans le moniteur série

int nombre = 25;

void setup() {
  Serial.begin(9600);
  Serial.println(nombre);
}

void loop() {
}

Serial.println() permet d'envoyer une valeur vers le moniteur série. La référence Arduino inclut Serial parmi les éléments de communication du langage. citeturn1search1
