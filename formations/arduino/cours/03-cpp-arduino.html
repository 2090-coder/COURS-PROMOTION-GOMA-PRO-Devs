Arduino 03 — Les variables

Après avoir appris à commander les LEDs sans variables, nous allons maintenant comprendre pourquoi les variables rendent un programme plus clair, flexible et facile à modifier.

1. Avant les variables : le problème

Dans le chapitre précédent, nous pouvions écrire directement les numéros des broches :

pinMode(13, OUTPUT); pinMode(12, OUTPUT); digitalWrite(13, HIGH); delay(500); digitalWrite(13, LOW); digitalWrite(12, HIGH); delay(500); digitalWrite(12, LOW);

Le programme fonctionne. Mais si la LED 1 passe de la broche 13 à la broche 8, il faut rechercher tous les 13 dans le programme.

2. Qu'est-ce qu'une variable ?

Une variable est une zone de mémoire à laquelle on donne un nom. Elle permet de mémoriser une valeur et de réutiliser cette valeur dans le programme.

led1 → 13
led2 → 12

Le nom led1 représente donc la valeur 13.

3. Première variable

int led1 = 13;
int → type de donnée.
led1 → nom de la variable.
= → affectation d'une valeur.
13 → valeur stockée.

La ligne signifie : « crée une variable entière appelée led1 et donne-lui la valeur 13 ».

4. Refaire l'exercice avec deux LEDs

int led1 = 13;
int led2 = 12;

void setup() {
  pinMode(led1, OUTPUT);
  pinMode(led2, OUTPUT);
}

void loop() {
  digitalWrite(led1, HIGH);
  delay(500);
  digitalWrite(led1, LOW);

  digitalWrite(led2, HIGH);
  delay(500);
  digitalWrite(led2, LOW);
}
Pourquoi est-ce mieux ?
Si la première LED passe de la broche 13 à la broche 8, on modifie seulement int led1 = 8;.

5. Une variable peut changer

int nombre = 10;
nombre = 20;
nombre = 30;

La variable garde son nom, mais sa valeur peut changer pendant l'exécution.

6. Les principaux types

  • int : nombres entiers.
  • float : nombres avec décimales.
  • char : un caractère.
  • bool : vrai ou faux.
  • long : entier pouvant représenter des valeurs plus grandes.
int age = 18;
float tension = 3.3;
char lettre = 'A';
bool moteurActif = true;

7. Modifier une variable

int compteur = 0;
compteur = compteur + 1;
compteur = compteur + 1;
compteur = compteur + 1;

Après ces trois instructions, compteur vaut 3.

compteur++;

Cette instruction augmente la valeur de 1.

8. Afficher une variable

int nombre = 25;

void setup() {
  Serial.begin(9600);
  Serial.println(nombre);
}

void loop() {
}

Le moniteur série permet de voir la valeur envoyée par Arduino.

9. Constante

const int led1 = 13;

const indique que la valeur est destinée à rester constante. C'est pratique pour une configuration comme le numéro d'une broche.
