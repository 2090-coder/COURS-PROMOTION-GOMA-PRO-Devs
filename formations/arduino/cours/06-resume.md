# Arduino 06 — Résumé

- Une entrée reçoit une information ; une sortie agit sur un élément.
- `digitalRead()` lit une entrée numérique.
- `INPUT_PULLUP` utilise une résistance de rappel interne.
- `analogRead()` lit une valeur analogique selon les capacités de la carte.
- Le potentiomètre est un premier exercice analogique.
- `analogWrite()` permet le PWM sur les broches compatibles.
- `map()` convertit une valeur d'une plage vers une autre.
- Les capteurs fournissent des données que le programme peut traiter.
