Arduino 13 — GPS et localisation

1. GPS et GNSS

Un module GPS/GNSS reçoit des signaux satellites et peut fournir position, heure et autres informations. Arduino documente notamment les messages NMEA et les projets GPS.

2. Communication série

Nous réutilisons Serial/UART : le module envoie des données que le microcontrôleur reçoit et interprète.

3. Projet localisation

Afficher la position sur le moniteur série puis sur l'OLED. Ajouter ensuite un enregistrement sur SD avec RTC pour créer un journal de déplacements.

TP

  1. Recevoir les données du module.
  2. Identifier les trames NMEA.
  3. Afficher latitude et longitude.
  4. Associer GPS + OLED + SD.

Résumé

  • GPS fournit une position à partir des satellites.
  • UART/Serial sert à recevoir les données.
  • NMEA est un format courant de messages GPS.
