Arduino 13 — GPS et GNSS

Comprendre le GPS, recevoir les données NMEA par UART, les décoder avec TinyGPSPlus et afficher une position réelle avec Arduino.

1. Qu'est-ce qu'un GPS ?

Un récepteur GPS reçoit les signaux de satellites et utilise les informations de temps et de distance apparente pour calculer une position. Le terme GNSS est plus général : selon le matériel, un récepteur peut exploiter plusieurs constellations de navigation.

Les informations courantes sont : latitude, longitude, altitude, vitesse, cap, date, heure et nombre de satellites utilisés.

Satellites → Récepteur GNSS → Trames NMEA → UART → Arduino → Décodage → Position

2. Les satellites et le calcul de position

Le récepteur compare les temps de propagation des signaux provenant de plusieurs satellites. Il construit des mesures de distance apparente, appelées pseudo-distances, puis résout sa position et l'erreur d'horloge.

Pour une solution complète de position et de temps, plusieurs satellites sont nécessaires. La qualité de la solution dépend notamment de la visibilité du ciel, de la géométrie des satellites et des conditions radio.

3. Le module GPS communique avec Arduino

Beaucoup de modules GPS/GNSS utilisent une liaison série UART pour transmettre leurs données.

4. Pourquoi TX et RX sont croisés ?

TX signifie transmission et RX réception. Une sortie TX doit donc aller vers une entrée RX :

GPS TX → Arduino RX
Arduino TX → GPS RX

Si TX est branché sur TX ou RX sur RX, la communication ne fonctionnera généralement pas comme prévu.

5. Les trames NMEA

Les récepteurs GNSS peuvent transmettre des messages textuels structurés selon NMEA. On y trouve notamment des informations de position, de temps, de vitesse et d'état du positionnement.

Le programme n'a pas besoin de décoder manuellement chaque champ : TinyGPSPlus peut analyser les données NMEA et fournir une interface Arduino plus simple.

6. Installer TinyGPSPlus

  1. Ouvrir Arduino IDE.
  2. Aller dans Outils / Gérer les bibliothèques selon la version de l'IDE.
  3. Rechercher TinyGPSPlus.
  4. Installer la bibliothèque de Mikal Hart.

La bibliothèque est conçue pour analyser les flux NMEA et extraire notamment position, date, heure, altitude, vitesse et cap.

7. Comprendre le programme

#include <SoftwareSerial.h>
#include <TinyGPS++.h>

SoftwareSerial gpsSerial(4, 3);
TinyGPSPlus gps;

void setup() {
  Serial.begin(9600);
  gpsSerial.begin(9600);
}

void loop() {
  while (gpsSerial.available() > 0) {
    gps.encode(gpsSerial.read());
  }

  if (gps.location.isUpdated()) {
    Serial.println(gps.location.lat(), 6);
    Serial.println(gps.location.lng(), 6);
  }
}

Étape 1 : SoftwareSerial crée une liaison série sur les broches choisies.

Étape 2 : TinyGPSPlus gps; crée l'objet qui va analyser les données GNSS.

Étape 3 : chaque caractère reçu est envoyé à gps.encode().

Étape 4 : isUpdated() permet de travailler lorsqu'une nouvelle position a été traitée.

9. `isValid()` ou `isUpdated()` ?

  • isValid() : la donnée actuellement disponible est considérée comme valide.
  • isUpdated() : une nouvelle donnée vient d'être reçue et traitée.

Pour afficher une position uniquement lorsqu'elle change, isUpdated() est particulièrement pratique.

11. Pourquoi parfois aucune position ?

Le module peut être alimenté et communiquer avec Arduino tout en n'ayant pas encore obtenu un fix. Il faut distinguer communication série et position valide.

  • Une antenne avec une bonne vue du ciel aide à l'acquisition.
  • Le premier fix peut demander du temps.
  • Un mauvais câblage TX/RX ou GND empêche la réception.
  • Un mauvais débit série peut produire des données incompréhensibles.
  • Un problème d'alimentation peut empêcher le module de fonctionner correctement.
