Arduino 09 — Systèmes embarqués et débogage

Nous abordons maintenant les notions plus avancées : temps, interruptions, timers, registres, bibliothèques et diagnostic.

1. Éviter les longs delay() avec millis()

unsigned long precedent = 0;
const unsigned long periode = 1000;

void loop() {
  unsigned long maintenant = millis();
  if (maintenant - precedent >= periode) {
    precedent = maintenant;
    // tâche périodique
  }
}

millis() permet de mesurer le temps écoulé et de créer des tâches périodiques sans bloquer aussi longtemps qu'un grand delay().

2. Interruptions

Une interruption permet au microcontrôleur de réagir à certains événements matériels sans attendre le déroulement normal du programme.

volatile bool evenement = false;

void reaction() {
  evenement = true;
}

void setup() {
  pinMode(2, INPUT_PULLUP);
  attachInterrupt(digitalPinToInterrupt(2), reaction, FALLING);
}

Une routine d'interruption doit rester courte. Les détails disponibles dépendent de la carte.

3. Timers

Les timers sont des ressources matérielles permettant notamment de mesurer des intervalles, produire certains signaux ou déclencher des événements. Leur utilisation directe dépend fortement du microcontrôleur.

4. Registres

Les fonctions Arduino simplifient la programmation. Les registres permettent, sur certaines cartes, de contrôler plus directement le matériel. Ils sont spécifiques à l'architecture : il faut donc consulter la documentation de la carte avant de les utiliser.

5. Bibliothèques

Une bibliothèque regroupe du code réutilisable pour une fonctionnalité ou un composant. Avant d'écrire une bibliothèque soi-même, il faut savoir installer, inclure et utiliser correctement une bibliothèque existante.

#include <Wire.h>

6. Débogage

  • Lire le message d'erreur de compilation.
  • Vérifier les broches et le câblage.
  • Afficher les variables avec Serial.println().
  • Tester un composant à la fois.
  • Réduire un programme complexe à un exemple minimal.
  • Documenter ce qui fonctionne et ce qui ne fonctionne pas.

7. Projet pratique — Feu tricolore

Créer un feu rouge-orange-vert de laboratoire avec une séquence claire. Ajouter un bouton de demande et gérer le temps avec une approche non bloquante.

8. Projet pratique — Station de mesure

Lire un capteur adapté, afficher les valeurs par port série et déclencher une indication lorsqu'un seuil est dépassé.

9. TP

  1. Remplacer un long delay() par millis().
  2. Observer un bouton avec une interruption sur une carte compatible.
  3. Diagnostiquer volontairement une petite erreur de programme à l'aide du moniteur série.
  4. Identifier dans la documentation de votre carte les timers et registres disponibles.

Résumé

  • millis() permet une gestion du temps plus souple.
  • Les interruptions répondent à certains événements matériels.
  • Les timers sont des ressources matérielles.
  • Les registres donnent un contrôle plus bas niveau, dépendant de la carte.
  • Les bibliothèques réutilisent du code.
  • Le débogage consiste à observer, isoler, tester et corriger.
