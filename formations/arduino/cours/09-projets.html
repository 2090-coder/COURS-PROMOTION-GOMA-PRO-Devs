Arduino 09 — Mémoire, EEPROM et stockage SD

Objectif : comprendre où Arduino stocke son programme et ses données, conserver des paramètres après extinction et enregistrer des mesures dans un fichier.

1. Les principales mémoires

  • Flash : contient principalement le programme.
  • SRAM : variables utilisées pendant l'exécution.
  • EEPROM : petite mémoire non volatile pour conserver des paramètres.
  • SD : stockage externe pour de grandes quantités de données.

2. EEPROM : conserver un réglage

#include <EEPROM.h>

int seuil = 50;
EEPROM.put(0, seuil);

int lu = 0;
EEPROM.get(0, lu);
Serial.println(lu);

put() écrit une variable ; get() la relit. On doit éviter les écritures inutiles afin de préserver la durée de vie de la mémoire.

3. SD : enregistrer des données

Une carte SD permet de créer des fichiers de journalisation : température, distance, événements ou états d'un système.

#include <SPI.h>
#include <SD.h>

if (SD.begin(10)) {
  File f = SD.open("log.txt", FILE_WRITE);
  if (f) {
    f.println("27.4,OK");
    f.close();
  }
}

La broche CS dépend du module et de la carte utilisée : elle doit être vérifiée dans son brochage.

4. Lire un fichier

File f = SD.open("log.txt");
if (f) {
  while (f.available()) {
    Serial.write(f.read());
  }
  f.close();
}

5. Concevoir un journal

Un format simple comme date,heure,valeur,etat facilite l'exploitation ultérieure dans un tableur ou un programme.

2026-09-14,15:30,27.4,OK
Attention : la capacité, les broches SPI, les tensions et les bibliothèques varient selon la carte et le module SD. Vérifier le matériel avant le câblage.

TP progressif

  1. Écrire un seuil dans l'EEPROM.
  2. Éteindre puis redémarrer et relire le seuil.
  3. Initialiser une SD.
  4. Créer un fichier de journal.
  5. Ajouter une nouvelle mesure périodiquement.
  6. Relire le fichier et afficher son contenu.

À retenir

  • Flash = programme, SRAM = travail, EEPROM = paramètres persistants.
  • La SD est adaptée à l'enregistrement de nombreux événements.
  • Les écritures EEPROM doivent être maîtrisées.
  • Fermer les fichiers après utilisation.
