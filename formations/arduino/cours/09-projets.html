Arduino 09 — Mémoire, EEPROM et stockage SD

Nous apprenons à conserver des informations, puis à enregistrer des mesures dans un support de stockage.

1. Les mémoires Arduino

  • Programme et données temporaires.
  • RAM : données utilisées pendant l'exécution.
  • Mémoire non volatile : conserver certaines informations après extinction.

2. EEPROM

#include <EEPROM.h>

int seuil = 50;
EEPROM.put(0, seuil);

int lu = 0;
EEPROM.get(0, lu);

La méthode exacte dépend de la carte. On doit respecter la capacité et le nombre d'écritures prévu par la mémoire.

3. Carte SD

Une carte SD permet de journaliser des mesures, événements ou paramètres. Nous étudierons l'initialisation, les fichiers, l'écriture et la lecture.

4. Journalisation

// Exemple de ligne logique
// date,heure,temperature,etat
2026-09-09,14:00,27.4,OK

Le but est de produire des données faciles à relire ensuite.

TP

  1. Sauvegarder un seuil dans l'EEPROM.
  2. Relire le seuil après redémarrage.
  3. Créer un fichier de journalisation sur SD avec un module compatible.
  4. Lire le fichier et afficher quelques lignes sur le moniteur série.

Résumé

  • La RAM sert aux données de travail.
  • L'EEPROM conserve certaines données hors tension.
  • La SD permet de stocker beaucoup plus de données.
  • Le stockage doit être utilisé avec une gestion correcte des écritures.
