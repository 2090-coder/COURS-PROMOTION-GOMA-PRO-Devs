Arduino 12 — OLED et affichage

Objectif : contrôler un petit écran OLED I²C, afficher du texte et transformer l'écran en interface de mesure.

1. Comprendre l'OLED

Un écran OLED transforme des données numériques en informations visuelles. Un modèle courant de laboratoire est le SSD1306 monochrome, souvent utilisé avec une interface I²C.

2. Connexion I²C

Le module utilise généralement VCC, GND, SDA et SCL. Les broches SDA/SCL exactes dépendent de la carte Arduino utilisée.

3. Bibliothèques

Un exemple courant utilise Adafruit_GFX pour les fonctions graphiques et Adafruit_SSD1306 pour le contrôleur SSD1306. Installer les bibliothèques compatibles avec votre matériel depuis le Library Manager.

4. Premier affichage

#include <Wire.h>
#include <Adafruit_GFX.h>
#include <Adafruit_SSD1306.h>

#define SCREEN_WIDTH 128
#define SCREEN_HEIGHT 64
Adafruit_SSD1306 display(SCREEN_WIDTH, SCREEN_HEIGHT, &Wire, -1);

void setup(){
  Serial.begin(9600);
  if(!display.begin(SSD1306_SWITCHCAPVCC, 0x3C)){
    Serial.println("OLED introuvable");
    while(true){}
  }
  display.clearDisplay();
  display.setTextSize(1);
  display.setTextColor(SSD1306_WHITE);
  display.setCursor(0,0);
  display.println("GOMA PRO Devs");
  display.println("Arduino OLED");
  display.display();
}
void loop(){}

L'adresse I²C 0x3C est fréquente mais n'est pas universelle. Si l'écran ne répond pas, vérifier son adresse.

5. Afficher une mesure

float distance = 25.4;
display.clearDisplay();
display.setCursor(0,0);
display.println("Distance");
display.print(distance,1);
display.println(" cm");
display.display();

6. Le principe du buffer

Le programme prépare l'image en mémoire avec les fonctions print(), drawLine(), etc. L'appel display.display() envoie ensuite le contenu vers l'écran.

7. Mini-interface

Avec deux boutons, on peut créer un menu : bouton 1 change de page, bouton 2 valide. Le programme peut afficher la distance, l'heure, la température ou l'état d'un système.

TP progressif

  1. Afficher un titre.
  2. Afficher un compteur.
  3. Afficher une valeur analogique.
  4. Afficher une distance HC-SR04.
  5. Afficher date et heure d'un RTC.
  6. Créer deux pages d'écran avec un bouton.

À retenir

  • OLED = sortie visuelle compacte.
  • I²C réduit généralement le nombre de fils.
  • La bibliothèque masque une grande partie des détails graphiques.
  • L'adresse I²C et la résolution doivent correspondre au module.
