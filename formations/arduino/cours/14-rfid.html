Arduino 14 — RFID

Objectif : comprendre l'identification sans contact, lire un UID avec un MFRC522 et construire une logique d'autorisation dans un laboratoire pédagogique.

1. Qu'est-ce que RFID ?

RFID signifie Radio Frequency Identification. Un lecteur communique avec un tag ou une carte sans contact direct. Le tag possède des informations que le lecteur peut récupérer selon le protocole utilisé.

2. Le module MFRC522

Le MFRC522 est un lecteur RFID 13,56 MHz couramment utilisé dans les projets Arduino. Dans un montage typique, il communique avec Arduino par SPI.

Les lignes courantes sont SDA/SS, SCK, MOSI, MISO, IRQ, GND, RST et 3.3V selon le module.

3. Installer la bibliothèque

Dans l'Arduino IDE, utiliser le Library Manager pour rechercher une bibliothèque compatible MFRC522. Toujours vérifier que la bibliothèque correspond au matériel utilisé.

4. Lire l'UID

#include <SPI.h>
#include <MFRC522.h>

#define SS_PIN 10
#define RST_PIN 9
MFRC522 rfid(SS_PIN, RST_PIN);

void setup(){
  Serial.begin(9600);
  SPI.begin();
  rfid.PCD_Init();
  Serial.println("Approchez une carte...");
}

void loop(){
  if(!rfid.PICC_IsNewCardPresent()) return;
  if(!rfid.PICC_ReadCardSerial()) return;

  Serial.print("UID : ");
  for(byte i=0;i<rfid.uid.size;i++){
    if(rfid.uid.uidByte[i] < 0x10) Serial.print("0");
    Serial.print(rfid.uid.uidByte[i], HEX);
    Serial.print(" ");
  }
  Serial.println();
  rfid.PICC_HaltA();
}

5. Comprendre l'UID

L'UID est un identifiant présenté par la carte. On peut le comparer à une valeur enregistrée pour simuler une autorisation locale.

bool autorise = true; // résultat d'une comparaison pédagogique
if(autorise){
  Serial.println("ACCES AUTORISE");
}else{
  Serial.println("ACCES REFUSE");
}
Important : un UID seul ne constitue pas une authentification forte. Le contenu de ce chapitre sert à apprendre RFID et la logique de contrôle dans un environnement de laboratoire autorisé.

6. RFID + OLED + LED

Une architecture pédagogique peut afficher l'UID sur OLED et allumer une LED selon le résultat. On apprend ainsi à faire coopérer SPI, I²C et sorties numériques.

TP progressif

  1. Initialiser SPI et le lecteur.
  2. Détecter une carte.
  3. Afficher son UID.
  4. Comparer un UID de test.
  5. Afficher Autorisé/Refusé sur OLED.
  6. Ajouter une journalisation locale.

À retenir

  • RFID permet une identification sans contact.
  • MFRC522 est un exemple de lecteur.
  • SPI est couramment utilisé avec ce module.
  • L'UID ne doit pas être présenté comme une sécurité forte à lui seul.
