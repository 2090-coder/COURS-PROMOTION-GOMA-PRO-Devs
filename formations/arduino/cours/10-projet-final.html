ARDUINO · CHAPITRE 10

Projet final professionnel

Le projet final rassemble progressivement les compétences acquises depuis l'environnement Arduino jusqu'au développement d'un système embarqué documenté.

1. Cahier des charges

  1. Définir le problème.
  2. Définir les entrées et sorties.
  3. Définir les contraintes.
  4. Choisir la carte et les composants.
  5. Définir les résultats attendus.

2. Conception

  • Faire le schéma fonctionnel.
  • Préparer le câblage.
  • Organiser le programme en fonctions.
  • Prévoir les états normaux et les erreurs.

3. Architecture du programme

// Variables et configuration

void setup() {
  // Initialisation
}

void loop() {
  // Lecture des entrées
  // Traitement
  // Commande des sorties
}

// Fonctions du projet

4. Développement progressif

  1. Tester chaque composant séparément.
  2. Faire fonctionner chaque sous-système.
  3. Réunir les sous-systèmes.
  4. Ajouter le traitement des erreurs.
  5. Nettoyer et commenter le code.

Projet A — Système de signalisation

Créer un système avec plusieurs LEDs, un bouton et une séquence contrôlée. Utiliser variables, conditions, fonctions et gestion du temps.

Projet B — Station de mesure

Lire un capteur adapté, afficher les valeurs sur le moniteur série et signaler une valeur hors seuil.

Projet C — Système embarqué complet

Concevoir un petit système réunissant au minimum une entrée, une sortie, un traitement, une fonction réutilisable et une communication série.

5. Tests et débogage

  1. Tester l'alimentation et le câblage.
  2. Tester les entrées.
  3. Tester les sorties.
  4. Observer les variables dans le moniteur série.
  5. Tester les différents scénarios.
  6. Documenter les corrections.

6. Livrables

  • Code source Arduino.
  • Schéma de câblage.
  • Liste des composants.
  • Résumé du fonctionnement.
  • Rapport de tests.
  • Présentation du projet.
