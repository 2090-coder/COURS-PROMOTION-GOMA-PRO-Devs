ARDUINO · CHAPITRE 10

Projet final professionnel

Le projet final rassemble les compétences acquises depuis l'installation de l'IDE jusqu'à la conception d'un système embarqué documenté.

1. Cahier des charges

  • Définir le problème à résoudre.
  • Définir les entrées, sorties et contraintes.
  • Choisir une carte adaptée.
  • Préparer la liste des composants.

2. Conception

  • Réaliser le schéma de câblage.
  • Définir l'alimentation adaptée à chaque composant.
  • Organiser le programme en fonctions et modules.
  • Prévoir les erreurs et les états anormaux.

3. Programmation

void setup() {
  // Initialisation du système
}

void loop() {
  // Lecture des entrées
  // Traitement
  // Commande des sorties
}

4. Tests

  1. Tester chaque composant séparément.
  2. Tester ensuite l'intégration complète.
  3. Utiliser le moniteur série pour observer les valeurs.
  4. Corriger les erreurs et documenter les résultats.

5. Livrables

  • Code source Arduino.
  • Schéma électronique.
  • Liste des composants.
  • Notice d'utilisation.
  • Rapport de tests.
  • Présentation du projet.

Évaluation / 100

  • Compréhension du besoin : 15
  • Montage et sécurité électrique : 20
  • Qualité du code : 25
  • Fonctionnement : 20
  • Tests et débogage : 10
  • Documentation et présentation : 10
