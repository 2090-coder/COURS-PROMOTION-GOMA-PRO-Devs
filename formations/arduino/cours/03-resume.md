# Arduino 03 — Résumé

- Une variable donne un nom à une valeur.
- Types étudiés : bool, boolean, char, unsigned char, byte, int, unsigned int, word, short, unsigned short, long, unsigned long, float, double, String et void pour les fonctions.
- `const` sert aux valeurs constantes.
- `++`, `--`, `+=` et `-=` modifient les valeurs.
- TP principal : chainillard de 5 LEDs, LED1 → LED5 puis LED5 → LED1.
- Les boucles ne sont pas utilisées dans le TP principal : elles viennent au chapitre 04.
