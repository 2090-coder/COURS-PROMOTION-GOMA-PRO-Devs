Arduino 11 — RTC et gestion de l'heure

Objectif : lire une date et une heure fiables, comprendre l'horodatage et déclencher des actions selon le temps.

1. Qu'est-ce qu'un RTC ?

RTC signifie Real-Time Clock. Le module conserve l'heure grâce à une horloge interne et généralement une alimentation de sauvegarde. Il est utile lorsque l'Arduino doit connaître la date même après un redémarrage.

2. Exemple DS3231 et I²C

Le DS3231 est un RTC couramment utilisé. Le module communique généralement en I²C avec SDA et SCL. Les broches exactes dépendent de la carte.

La bibliothèque RTClib peut être installée depuis le gestionnaire de bibliothèques de l'Arduino IDE.

3. Premier programme

#include <Wire.h>
#include <RTClib.h>

RTC_DS3231 rtc;

void setup(){
  Serial.begin(9600);
  Wire.begin();
  if(!rtc.begin()){
    Serial.println("RTC introuvable");
    while(true){}
  }
}

void loop(){
  DateTime now = rtc.now();
  Serial.print(now.day()); Serial.print('/');
  Serial.print(now.month()); Serial.print('/');
  Serial.print(now.year()); Serial.print(' ');
  Serial.print(now.hour()); Serial.print(':');
  Serial.print(now.minute()); Serial.print(':');
  Serial.println(now.second());
  delay(1000);
}

4. Comprendre DateTime

  • day() : jour.
  • month() : mois.
  • year() : année.
  • hour() : heure.
  • minute() : minute.
  • second() : seconde.

5. Régler l'heure

Lors de la première configuration, on peut initialiser l'horloge avec l'heure de compilation ou avec une date fournie par le programme. Il faut ensuite éviter de remettre automatiquement l'heure à chaque démarrage.

// Exemple conceptuel lors de la mise en service
rtc.adjust(DateTime(F(__DATE__), F(__TIME__)));

6. Créer une alarme logique

if(now.hour() == 18 && now.minute() == 0){
  Serial.println("Evenement programme");
}

Pour éviter de déclencher l'événement plusieurs fois pendant la même minute, on ajoute généralement une logique d'état.

7. RTC + capteur + SD

Une architecture classique consiste à lire le RTC, mesurer un capteur puis enregistrer date,heure,valeur sur une carte SD. Cette combinaison prépare les systèmes de journalisation professionnels.

TP progressif

  1. Détecter le RTC.
  2. Afficher date et heure.
  3. Régler l'horloge lors de la mise en service.
  4. Créer un événement à une heure donnée.
  5. Associer RTC + capteur + journalisation SD.

À retenir

  • RTC = horloge temps réel.
  • I²C permet généralement sa communication.
  • L'horodatage donne un contexte temporel aux mesures.
  • Un bon programme évite de réinitialiser inutilement l'heure.
