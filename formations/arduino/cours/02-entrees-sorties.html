ARDUINO — CHAPITRE 02

Premiers programmes : deux LEDs

Nous commandons directement les broches, toujours sans variables.

1. Configurer une sortie

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
}

La broche 13 devient une sortie.

2. Allumer et éteindre

digitalWrite(13, HIGH);

digitalWrite(13, LOW);

HIGH produit l'état haut et LOW l'état bas.

3. Attendre avec delay()

digitalWrite(13, HIGH);
delay(1000);
digitalWrite(13, LOW);
delay(1000);

4. Premier clignotement

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}

5. Deux LEDs l'une après l'autre

LED 1 sur 13 et LED 2 sur 12, avec les résistances adaptées et une masse commune.

void setup() {
  pinMode(13, OUTPUT);
  pinMode(12, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  digitalWrite(12, LOW);
  delay(1000);

  digitalWrite(13, LOW);
  digitalWrite(12, HIGH);
  delay(1000);
}

6. Exercices

  1. Faire clignoter les deux LEDs ensemble.
  2. Faire durer LED 13 deux secondes et LED 12 une seconde.
  3. Créer la séquence 13 → 12 → 13 → 12.
  4. Modifier les temps d'attente.

Résumé

  • pinMode() configure une broche.
  • digitalWrite() commande son état.
  • HIGH et LOW représentent deux états logiques.
  • delay() crée une attente.
  • Nous savons maintenant réaliser une séquence avec plusieurs LEDs sans variables.
