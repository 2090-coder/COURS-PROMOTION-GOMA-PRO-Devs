ARDUINO — CHAPITRE 02

Premiers programmes : deux LEDs

Nous programmons maintenant des sorties numériques, sans variables, afin de comprendre les instructions une par une.

1. Ce que nous avons déjà appris

Dans le chapitre 01, nous avons découvert la carte Arduino, l'IDE, la compilation, le téléversement et la structure setup()/loop(). Nous avons aussi découvert pinMode().

Règle pédagogique : dans ce chapitre, nous n'utilisons volontairement pas de variables. Nous voulons comprendre le fonctionnement des instructions avant d'apprendre à donner des noms aux valeurs.

2. Configurer une LED comme sortie

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
}

pinMode(13, OUTPUT) indique à Arduino que la broche 13 sera utilisée comme sortie.

3. Allumer la LED

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
}

digitalWrite(13, HIGH) demande à Arduino de placer la broche 13 à l'état logique HIGH.

4. Éteindre la LED

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, LOW);
}

LOW demande l'état logique bas.

5. Faire clignoter une LED

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
  delay(1000);
}

Arduino allume la LED, attend 1 seconde, l'éteint, attend 1 seconde, puis recommence.

6. Premier exercice : deux LEDs l'une après l'autre

Brancher une première LED sur la broche 13 et une deuxième LED sur la broche 12, avec les résistances adaptées et une masse commune.

void setup() {
  pinMode(13, OUTPUT);
  pinMode(12, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
  digitalWrite(12, LOW);
  delay(1000);

  digitalWrite(13, LOW);
  digitalWrite(12, HIGH);
  delay(1000);
}

Résultat : LED 1 allumée → attente → LED 1 éteinte et LED 2 allumée → attente → le cycle recommence.

7. Comprendre exactement l'ordre des instructions

  1. Arduino configure 13 comme sortie.
  2. Arduino configure 12 comme sortie.
  3. La broche 13 passe à HIGH.
  4. La broche 12 passe à LOW.
  5. Arduino attend 1000 ms.
  6. La broche 13 passe à LOW.
  7. La broche 12 passe à HIGH.
  8. Arduino attend encore 1000 ms.
  9. loop() recommence.

8. Exercices progressifs

Exercice 1 : faire clignoter les deux LEDs ensemble.
Exercice 2 : faire rester la LED 13 allumée pendant 2 secondes et la LED 12 pendant 1 seconde.
Exercice 3 : créer une séquence LED 13 → LED 12 → LED 13 → LED 12.
Exercice 4 : modifier les temps d'attente pour obtenir une séquence plus rapide.

9. Questions de compréhension

  1. À quoi sert pinMode() ?
  2. Quelle différence entre HIGH et LOW ?
  3. À quoi sert digitalWrite() ?
  4. À quoi sert delay(1000) ?
  5. Pourquoi avons-nous utilisé deux appels à pinMode() ?
  6. Pourquoi n'avons-nous pas encore créé de variable ?

10. Ce qu'il faut retenir

Avant d'apprendre les variables, il faut savoir commander directement une broche. Nous savons maintenant configurer une sortie, l'allumer, l'éteindre, attendre et construire une séquence de plusieurs sorties.

Au chapitre 03 : nous allons reprendre exactement ces mêmes exercices et apprendre pourquoi les variables rendent le programme plus lisible, plus facile à modifier et plus réutilisable.
