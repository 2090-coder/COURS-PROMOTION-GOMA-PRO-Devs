Arduino 02 — Entrées, sorties et PWM

Comprendre les GPIO, les boutons, les entrées analogiques et la commande de puissance par PWM.

1. GPIO

Une broche numérique peut être configurée en INPUT, INPUT_PULLUP ou OUTPUT.

pinMode()digitalRead()digitalWrite()

2. Bouton et LED

const int bouton = 2;
const int led = 13;

void setup() {
  pinMode(bouton, INPUT_PULLUP);
  pinMode(led, OUTPUT);
}

void loop() {
  bool appuye = digitalRead(bouton) == LOW;
  digitalWrite(led, appuye ? HIGH : LOW);
}

Avec INPUT_PULLUP, le bouton est généralement relié entre la broche et GND.

3. Entrée analogique

analogRead() mesure une tension sur une entrée analogique. Sur de nombreuses cartes Arduino classiques, la valeur est lue sur une échelle de 0 à 1023.

int valeur = analogRead(A0);
Serial.println(valeur);

4. PWM

Le PWM permet de commander progressivement une sortie compatible, par exemple la luminosité d'une LED.

const int led = 9;
void setup(){ pinMode(led, OUTPUT); }
void loop(){
  for(int p=0;p<=255;p++) { analogWrite(led,p); delay(5); }
  for(int p=255;p>=0;p--) { analogWrite(led,p); delay(5); }
}

5. TP

  1. Lire un potentiomètre sur A0.
  2. Afficher sa valeur dans le moniteur série.
  3. Transformer cette valeur en luminosité LED avec map().
  4. Ajouter un bouton pour activer/désactiver le système.

À retenir

GPIO = communication avec le monde extérieur. Analogique = mesure. PWM = commande progressive d'une sortie compatible.
