Arduino 05 — Les fonctions

Après les variables, les conditions et les boucles, nous allons apprendre à organiser un programme avec des fonctions.

1. Pourquoi les fonctions ?

Un programme devient rapidement long lorsqu'on répète les mêmes instructions. Une fonction permet de regrouper des instructions sous un nom que l'on peut appeler plusieurs fois.

On peut donc passer de :

digitalWrite(13, HIGH);
delay(500);
digitalWrite(13, LOW);
delay(500);

digitalWrite(13, HIGH);
delay(500);
digitalWrite(13, LOW);
delay(500);

à une organisation plus claire :

clignoter();
clignoter();

2. Première fonction

void clignoter() {
  digitalWrite(13, HIGH);
  delay(500);
  digitalWrite(13, LOW);
  delay(500);
}
void : la fonction ne renvoie pas de valeur.
clignoter : le nom de la fonction.
() : les paramètres éventuels seront placés ici.
{ } : contient les instructions de la fonction.

3. Appeler une fonction

Définir une fonction ne suffit pas. Il faut l'appeler pour exécuter son contenu.

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  clignoter();
}

void clignoter() {
  digitalWrite(13, HIGH);
  delay(500);
  digitalWrite(13, LOW);
  delay(500);
}

Lorsque le programme arrive à clignoter();, Arduino exécute les instructions de cette fonction puis revient à l'endroit où elle a été appelée.

4. Fonction avec un paramètre

Une fonction peut recevoir une information.

void allumer(int broche) {
  digitalWrite(broche, HIGH);
}

On peut alors écrire :

allumer(13);
allumer(12);

Ici, broche reçoit successivement les valeurs 13 puis 12.

5. Fonction avec plusieurs paramètres

void clignoter(int broche, int temps) {
  digitalWrite(broche, HIGH);
  delay(temps);
  digitalWrite(broche, LOW);
  delay(temps);
}

Exemple :

clignoter(13, 500);
clignoter(12, 1000);

La même fonction peut donc être réutilisée avec différentes LEDs et différents temps.

6. Fonction qui retourne une valeur

Une fonction peut également calculer une valeur et la retourner avec return.

int additionner(int a, int b) {
  return a + b;
}

int resultat = additionner(5, 3);

La fonction retourne ici 8, qui est stocké dans resultat.

7. Variables locales

void exemple() {
  int nombre = 10;
}

La variable créée à l'intérieur de la fonction est locale à cette fonction. Elle ne doit pas être considérée comme une variable globale du programme.

8. Organiser un programme Arduino

Un programme peut maintenant être organisé avec :

  • des variables pour mémoriser les valeurs ;
  • setup() pour l'initialisation ;
  • loop() pour le fonctionnement répété ;
  • des fonctions pour séparer les différentes tâches.

Cette organisation rend le programme plus lisible et plus facile à modifier.
