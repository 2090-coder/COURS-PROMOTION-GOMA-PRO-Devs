Arduino 05 — Les fonctions

Après les variables, conditions et boucles, nous apprenons à créer nos propres fonctions pour organiser le programme.

1. Pourquoi une fonction ?

Une fonction regroupe des instructions sous un nom. On peut ensuite l'appeler plusieurs fois au lieu de recopier le même code.

void clignoter() {
  digitalWrite(13, HIGH);
  delay(500);
  digitalWrite(13, LOW);
  delay(500);
}

2. Appeler une fonction

void setup() { pinMode(13, OUTPUT); }
void loop() { clignoter(); }

void clignoter() {
  digitalWrite(13, HIGH);
  delay(500);
  digitalWrite(13, LOW);
  delay(500);
}

3. Paramètres

void allumer(int broche) {
  digitalWrite(broche, HIGH);
}

allumer(13);
allumer(12);

Un paramètre permet de transmettre une valeur à la fonction.

4. Plusieurs paramètres

void clignoter(int broche, int temps) {
  digitalWrite(broche, HIGH);
  delay(temps);
  digitalWrite(broche, LOW);
  delay(temps);
}

5. Retourner une valeur

int additionner(int a, int b) {
  return a + b;
}

int resultat = additionner(5, 3);

6. Organiser un programme

Nous pouvons maintenant utiliser des variables pour les données, setup() pour l'initialisation, loop() pour le fonctionnement répété et nos propres fonctions pour séparer les tâches.

7. TP

  3. Réutiliser cette fonction avec deux LEDs.
  4. Créer une fonction qui retourne une somme.

Résumé

  • Une fonction regroupe des instructions.
  • On définit puis on appelle une fonction.
  • Les paramètres transmettent des valeurs.
  • return renvoie une valeur.
  • Les fonctions rendent le programme plus clair et réutilisable.
