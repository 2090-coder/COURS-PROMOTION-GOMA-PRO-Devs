Arduino 05 — Registres et accès bas niveau

Concept

Les fonctions Arduino simplifient le matériel. Les registres permettent d'aller plus près du microcontrôleur et de comprendre précisément la configuration des ports.

DDR, PORT et PIN

Sur les AVR classiques, DDR configure entrée/sortie, PORT configure la sortie ou la résistance interne, et PIN permet notamment de lire l'état.

// Exemple conceptuel AVR
DDRB |= (1 << PB5);      // PB5 en sortie
PORTB |= (1 << PB5);    // sortie à 1
PORTB &= ~(1 << PB5);   // sortie à 0

Masques binaires

#define BIT(n) (1U << (n))
registre |= BIT(3);     // mettre bit 3 à 1
registre &= ~BIT(3);    // mettre bit 3 à 0
registre ^= BIT(3);     // inverser bit 3

Attention

Les noms et registres varient selon le microcontrôleur. Un code AVR ne doit pas être copié tel quel sur toutes les cartes Arduino, notamment les cartes basées sur ESP32.
