Arduino 10 — Capteur ultrasonique

Le capteur HC-SR04 sert à introduire la mesure du temps et de la distance.

1. Principe

Le module émet une impulsion ultrasonique et mesure le temps de retour de l'écho. Le programme transforme cette durée en distance.

2. Connexions

VCC, GND, TRIG et ECHO. Vérifier la tension logique et la compatibilité avec la carte utilisée avant le câblage.

3. Première mesure

const int trig = 9;
const int echo = 10;

void setup() {
  pinMode(trig, OUTPUT);
  pinMode(echo, INPUT);
  Serial.begin(9600);
}

void loop() {
  digitalWrite(trig, LOW);
  delayMicroseconds(2);
  digitalWrite(trig, HIGH);
  delayMicroseconds(10);
  digitalWrite(trig, LOW);

  unsigned long duree = pulseIn(echo, HIGH);
  float distance = duree * 0.0343 / 2.0;
  Serial.println(distance);
  delay(200);
}

4. Exploitation

Afficher la distance, définir un seuil et commander une LED ou un buzzer lorsque l'objet est proche.

TP

  1. Mesurer une distance et l'afficher.
  2. Afficher une alerte sous un seuil.
  3. Créer un mini détecteur de proximité avec LED.

Résumé

  • TRIG déclenche la mesure.
  • ECHO fournit une durée.
  • La durée est convertie en distance.
  • Le capteur permet de construire des systèmes de détection.
