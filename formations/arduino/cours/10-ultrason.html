Arduino 10 — Ultrason et capteurs de distance

Objectif : comprendre comment le HC-SR04 transforme un temps de propagation en distance et utiliser cette mesure dans un programme.

1. Principe physique

Le capteur envoie une impulsion ultrasonique. L'onde se réfléchit sur un objet puis revient vers le récepteur. Arduino mesure la durée entre l'émission et le retour.

Comme l'onde fait un aller-retour, on divise la distance parcourue par deux.

2. Broches

  • VCC : alimentation.
  • GND : référence électrique.
  • TRIG : commande de déclenchement.
  • ECHO : durée du retour.

Vérifier la compatibilité des niveaux logiques du module et de la carte.

3. Première mesure

const byte TRIG = 9;
const byte ECHO = 10;

void setup(){
  pinMode(TRIG,OUTPUT);
  pinMode(ECHO,INPUT);
  Serial.begin(9600);
}

void loop(){
  digitalWrite(TRIG,LOW);
  delayMicroseconds(2);
  digitalWrite(TRIG,HIGH);
  delayMicroseconds(10);
  digitalWrite(TRIG,LOW);

  unsigned long duree = pulseIn(ECHO,HIGH,30000);
  if(duree == 0){
    Serial.println("Aucun echo");
  } else {
    float distance = duree * 0.0343 / 2.0;
    Serial.print("Distance : ");
    Serial.print(distance,1);
    Serial.println(" cm");
  }
  delay(200);
}

4. Pourquoi 0,0343 ?

La vitesse du son dans l'air est approximativement de 343 m/s à température ambiante, soit environ 0,0343 cm par microseconde. La formule pédagogique devient donc :

distance = durée × 0,0343 / 2

5. Exploiter la mesure

if(distance < 20){
  digitalWrite(LED_BUILTIN,HIGH);
}else{
  digitalWrite(LED_BUILTIN,LOW);
}

On peut ainsi créer un indicateur de proximité.

TP progressif

  1. Mesurer une distance.
  2. Afficher une décimale.
  3. Détecter l'absence d'écho.
  4. Créer un seuil de 20 cm.
  5. Commander une LED selon le seuil.
  6. Ajouter un buzzer dans un montage pédagogique à basse tension.

À retenir

  • TRIG déclenche la mesure.
  • ECHO fournit une durée.
  • La distance tient compte de l'aller-retour.
  • Un délai d'attente évite de bloquer indéfiniment le programme.
