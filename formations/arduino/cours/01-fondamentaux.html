ARDUINO — CHAPITRE 01

Découvrir l'environnement Arduino

Avant de programmer, on découvre Arduino, la carte, l'IDE et le langage.

1. Qu'est-ce qu'Arduino ?

Arduino est une plateforme de prototypage électronique basée sur des cartes à microcontrôleur et un environnement de programmation. Le programme est préparé sur l'ordinateur puis téléversé vers la carte.

2. La carte Arduino

  • Microcontrôleur : exécute le programme.
  • USB : communication avec l'ordinateur et alimentation selon le modèle.
  • Broches numériques : entrées/sorties logiques.
  • Entrées analogiques : lecture de signaux analogiques selon la carte.
  • GND : référence commune du circuit.
  • Broches d'alimentation : selon le modèle.

Sur une Arduino Uno classique, la broche 13 est associée à la LED intégrée.

3. L'environnement Arduino IDE

  1. Installer Arduino IDE.
  2. Brancher la carte.
  3. Sélectionner la carte.
  4. Sélectionner le port.
  5. Écrire le sketch.
  6. Vérifier/compiler.
  7. Téléverser.

4. Le langage Arduino

Le « langage Arduino » utilise la syntaxe du C/C++ avec les fonctions et outils fournis par l'environnement Arduino. Nous allons apprendre les notions progressivement, sans commencer directement par les variables.

5. Structure minimale

void setup() {
}

void loop() {
}

setup() sert aux initialisations. loop() est exécutée continuellement.

6. Premier code : aucune variable

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
}

pinMode(13, OUTPUT); configure directement la broche 13 comme sortie. Les variables seront étudiées après les premiers exercices.

7. Première commande

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
}

On demande maintenant à la broche 13 de prendre l'état logique HIGH.

8. TP préparatoire

  1. Identifier les principales parties de votre carte.
  2. Installer et ouvrir Arduino IDE.
  3. Sélectionner la carte et le port.
  4. Compiler le premier code.
  5. Le téléverser.
  6. Ajouter ensuite digitalWrite(13, HIGH); et observer.

Résumé

  • Arduino relie programmation et électronique.
  • La carte contient un microcontrôleur.
  • IDE permet d'écrire, compiler et téléverser.
  • setup() initialise.
  • loop() se répète.
  • pinMode() configure une broche.
  • Nous commençons sans variables.
