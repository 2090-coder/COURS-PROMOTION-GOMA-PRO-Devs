ARDUINO — CHAPITRE 01

Découvrir l'environnement Arduino

Avant de programmer, on apprend ce qu'est Arduino, comment fonctionne la carte, comment installer l'environnement et comment envoyer un premier programme.

1. Objectifs

À la fin de ce chapitre, l'apprenant doit pouvoir :

  • expliquer simplement ce qu'est Arduino ;
  • identifier les principales parties d'une carte Arduino ;
  • comprendre la différence entre une entrée et une sortie ;
  • installer et ouvrir Arduino IDE ;
  • connecter une carte au PC ;
  • choisir la carte et le port ;
  • compiler et téléverser un programme ;
  • comprendre les deux fonctions setup() et loop() ;
  • écrire une première instruction Arduino sans variable.

2. Qu'est-ce qu'Arduino ?

Arduino est une plateforme de prototypage électronique basée notamment sur des cartes à microcontrôleur et des outils logiciels. Le programme est préparé sur l'ordinateur puis envoyé à la carte. La carte peut ensuite lire des informations et commander des composants.

Exemples : allumer une LED, lire un bouton, mesurer une tension avec un capteur, commander un moteur ou afficher une information.

À retenir :

Arduino fait le lien entre programme, électronique et monde réel.

3. Qu'est-ce qu'une carte Arduino ?

Une carte Arduino contient un microcontrôleur et différents éléments permettant de l'alimenter, de la programmer et de connecter des composants. Les détails varient selon le modèle.

  • Microcontrôleur : exécute le programme.
  • Port USB : sert généralement à communiquer avec l'ordinateur et peut fournir l'alimentation.
  • Broches numériques : permettent notamment de lire ou produire des états logiques.
  • Entrées analogiques : permettent de mesurer des signaux analogiques selon les capacités de la carte.
  • GND : référence électrique commune du circuit.
  • Alimentation : les tensions et possibilités dépendent du modèle ; il faut toujours consulter sa documentation.

Sur une Arduino Uno classique, la broche 13 est associée à la LED intégrée de la carte, ce qui permet de réaliser certains premiers exercices sans ajouter immédiatement une LED externe.

4. Entrée et sortie : l'idée fondamentale

Une entrée reçoit une information. Une sortie agit sur quelque chose.

  • Bouton → Arduino : entrée.
  • Capteur → Arduino : entrée.
  • Arduino → LED : sortie.
  • Arduino → buzzer : sortie.

Cette distinction sera étudiée avec des exercices pratiques dans les chapitres suivants.

5. Qu'est-ce que l'Arduino IDE ?

L'Arduino IDE est l'environnement dans lequel on écrit, vérifie et téléverse les sketches Arduino. La documentation officielle propose actuellement Arduino IDE 2 et explique notamment l'installation, l'ajout d'un paquet de carte, le téléversement et le moniteur série. citeturn0search0turn0search2

  1. Installer Arduino IDE.
  2. Ouvrir Arduino IDE.
  3. Brancher la carte avec un câble USB adapté.
  4. Attendre que l'ordinateur détecte la carte.
  5. Sélectionner le modèle de carte.
  6. Sélectionner le port correspondant.
  7. Écrire ou ouvrir un sketch.
  8. Cliquer sur Vérifier pour compiler.
  9. Cliquer sur Téléverser pour envoyer le programme à la carte.

Arduino explique également que le programme est préparé puis compilé avant d'être transféré vers la mémoire du microcontrôleur. citeturn0search6

6. Le langage Arduino

Quand on dit « langage Arduino », on parle de la façon de programmer les cartes Arduino avec la syntaxe du C/C++ et les fonctions fournies par l'environnement Arduino. La référence officielle organise notamment le langage autour de la structure, des valeurs/variables et des fonctions. citeturn0search1

Dans ce premier chapitre, nous ne commençons volontairement pas par les variables. Nous allons d'abord comprendre la carte et quelques instructions simples.

7. La structure minimale d'un programme

void setup() {
}

void loop() {
}

setup() est exécutée au démarrage pour les initialisations. Ensuite, loop() est exécutée encore et encore.

Question :

Si loop() contient une instruction qui allume une LED, que se passe-t-il lorsque le programme tourne ?

8. Premier code — sans variable

Voici volontairement un code très simple. Nous n'utilisons encore aucun nom de variable.

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
}

Ligne 1 : début de setup().

Ligne 2 : pinMode(13, OUTPUT) indique que la broche 13 doit être utilisée comme sortie.

Ligne 3 : fin de setup().

Pourquoi pas de variable ? Parce que l'objectif est d'abord de comprendre directement la relation entre une instruction et une broche. Les variables viendront seulement après les premiers exercices.

9. Première manipulation : écrire sur la broche 13

Ajoutons maintenant une instruction dans loop() :

void setup() {
  pinMode(13, OUTPUT);
}

void loop() {
  digitalWrite(13, HIGH);
}

digitalWrite(13, HIGH) demande à Arduino de placer la broche 13 à l'état logique haut. La signification électrique exacte dépend de la carte et de son alimentation.

La fonction digitalWrite() fait partie des fonctions officielles d'E/S numériques Arduino. citeturn0search1

10. Éteindre la sortie

Pour produire l'état bas :

digitalWrite(13, LOW);

Nous avons maintenant trois instructions essentielles à retenir pour le début :

  • pinMode() : définir le rôle de la broche ;
  • digitalWrite() : écrire un état numérique ;
  • delay() : attendre un certain temps en millisecondes.

Ces fonctions sont documentées dans la référence officielle Arduino. citeturn0search1

11. TP préparatoire

Exercice 1 — Identifier la carte

Sur votre carte, trouvez le microcontrôleur, le port USB, GND, 5V si présent sur votre modèle, les broches numériques et les entrées analogiques.

Exercice 2 — Préparer l'IDE

Installer Arduino IDE, brancher la carte, sélectionner le modèle et le port, puis vérifier un sketch vide.

Exercice 3 — Première instruction

Écrire uniquement le programme de la section 8, le compiler et le téléverser.

Exercice 4 — Observation

Modifier le programme pour ajouter digitalWrite(13, HIGH); dans loop(). Observer la carte et expliquer ce qui change.

12. Ce que nous n'apprenons PAS encore

Pour respecter une vraie progression, nous reportons volontairement :

  • les variables ;
  • les types int, float, bool ;
  • les conditions if/else ;
  • les boucles for et while ;
  • les fonctions personnelles ;
  • les tableaux et structures ;
  • les interruptions et registres.

Chaque notion sera introduite après que l'apprenant aura compris la précédente.

13. Résumé à mémoriser

  • Arduino = carte + microcontrôleur + environnement de programmation.
  • Le programme est écrit sur le PC puis téléversé vers la carte.
  • setup() s'exécute au démarrage.
  • loop() se répète.
  • pinMode() configure une broche.
  • digitalWrite() écrit un état numérique.
  • Nous commençons sans variables.
