ARDUINO — CHAPITRE 01

Les fondamentaux

Découvrir Arduino, comprendre une carte, installer l'environnement et écrire son premier programme.

1. Objectifs

  • Comprendre ce qu'est une carte Arduino.
  • Identifier microcontrôleur, alimentation, broches numériques et analogiques.
  • Comprendre la structure d'un programme Arduino.
  • Utiliser setup() et loop().
  • Compiler et téléverser un programme.

2. Qu'est-ce qu'Arduino ?

Arduino est une plateforme de prototypage électronique composée de cartes à microcontrôleur et d'un environnement de développement. Elle permet de lire des capteurs, commander des LED, moteurs, écrans et autres composants.

Le microcontrôleur exécute le programme enregistré dans sa mémoire. Les broches permettent au programme d'échanger avec le monde extérieur.

3. Entrées et sorties

Une entrée permet de lire une information, par exemple l'état d'un bouton. Une sortie permet de commander un élément, par exemple allumer une LED.

Une broche numérique travaille généralement avec deux états logiques : LOW et HIGH. Une entrée analogique permet de mesurer une tension sous forme d'une valeur numérique selon la carte utilisée.

4. Structure d'un programme

void setup() {
  // Initialisation exécutée une fois
}

void loop() {
  // Instructions répétées en permanence
}

setup() est exécutée une fois au démarrage. loop() est ensuite répétée continuellement.

5. Premier programme : LED

const int LED = 13;

void setup() {
  pinMode(LED, OUTPUT);
}

void loop() {
  digitalWrite(LED, HIGH);
  delay(1000);
  digitalWrite(LED, LOW);
  delay(1000);
}

Ce programme configure la broche comme sortie, allume la LED pendant une seconde, l'éteint pendant une seconde, puis recommence.

6. Variables et types

int compteur = 0;
float temperature = 25.5;
bool actif = true;
char lettre = 'A';

Une variable possède un nom et un type. Le choix du type dépend de la valeur que l'on souhaite stocker.

7. Fonctions utiles

  • pinMode() : configure une broche.
  • digitalWrite() : écrit un état numérique.
  • digitalRead() : lit un état numérique.
  • analogRead() : lit une entrée analogique.
  • delay() : attend un nombre de millisecondes.
  • Serial.begin() : initialise la communication série.

8. Travaux pratiques

TP 01 — Feu clignotant
