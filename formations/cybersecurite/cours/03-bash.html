CYBERSÉCURITÉ · CHAPITRE 03

Bash et automatisation

Bash permet d'automatiser des opérations répétitives d'administration.

Script simple

#!/usr/bin/env bash
set -euo pipefail

LOG="application.log"
if [[ -f "$LOG" ]]; then
  grep -c "ERROR" "$LOG"
else
  echo "Journal absent"
fi

Variables et boucles

for fichier in *.log; do
  echo "Analyse : $fichier"
done

Bonnes pratiques

  • Utiliser des guillemets autour des variables lorsque nécessaire.
  • Activer un mode d'erreur adapté comme set -euo pipefail.
  • Tester les scripts dans un environnement de laboratoire.
  • Éviter les commandes destructives dans les exercices.
