Python pour la sécurité

Python est utile pour automatiser des tâches d'administration, analyser des fichiers et produire des rapports dans des environnements autorisés.

Lecture de fichier

from pathlib import Path

journal = Path("application.log")
for ligne in journal.read_text(encoding="utf-8").splitlines():
    if "ERROR" in ligne:
        print(ligne)

Exceptions

try:
    valeur = int(input("Nombre : "))
except ValueError:
    print("Valeur invalide")

Bonnes pratiques

  • Travailler uniquement sur des systèmes autorisés.
  • Ne pas exécuter de code inconnu sans l'analyser.
  • Ne jamais stocker des mots de passe ou clés dans le code.
  • Documenter les scripts d'administration.
