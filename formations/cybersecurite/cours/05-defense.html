CYBERSÉCURITÉ · CHAPITRE 05

Analyse défensive et durcissement

La sécurité consiste notamment à réduire les risques, détecter les anomalies et corriger les mauvaises configurations.

Méthode

  1. Inventorier les actifs du laboratoire.
  2. Identifier les services nécessaires.
  3. Réduire les privilèges.
  4. Configurer les journaux.
  5. Surveiller les événements.
  6. Corriger et vérifier.

Exemple de contrôle

# Vérifier l'utilisateur courant
whoami

# Vérifier les processus
ps aux

# Examiner les derniers journaux
journalctl --no-pager -n 50

TP défensif

  1. Construire une machine virtuelle de laboratoire.
  2. Créer une configuration volontairement faible mais non dangereuse.
  3. Documenter les risques.
  4. Appliquer des corrections.
  5. Comparer l'état avant/après.

Règle : les tests de sécurité doivent être réalisés uniquement sur des systèmes dont vous avez l'autorisation.
