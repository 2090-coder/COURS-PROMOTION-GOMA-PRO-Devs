# COURS-PROMOTION-GOMA-PRO-Devs

Plateforme pédagogique de la 6e promotion de GOMA PRO Devs.

## Objectif

Ce dépôt est consacré aux cours, exercices, projets, bibliothèques et ressources pédagogiques. Il est séparé du dépôt d'inscription `INSCRIPTION-GOMA-PRO-Devs`.

## Formations

1. Arduino — C/C++, microcontrôleurs, programmation bas niveau, registres, mémoire, interruptions, timers, ADC, PWM, UART, I2C, SPI, structures, classes, création de bibliothèques et projets.
2. Web Frontend — HTML, CSS et JavaScript.
3. Web Backend — PHP et SQL.
4. Cybersécurité — Python, Linux et Bash, avec une approche légale, défensive et pédagogique.
5. Informatique complet — programmation, systèmes, bases de données, architecture et réseaux informatiques en profondeur.

## Organisation pédagogique

Chaque module est prévu avec :

- cours théorique ;
- exemples ;
- travaux pratiques ;
- exercices ;
- projets ;
- fichiers sources ;
- documents téléchargeables ;
- ressources complémentaires.

## Protection des formations

Chaque parcours doit disposer d'un contrôle d'accès séparé. Les mots de passe ne doivent jamais être placés dans les fichiers HTML, CSS ou JavaScript d'un dépôt public. Pour une protection réelle, l'authentification devra être traitée côté serveur avec des mots de passe hachés et des sessions sécurisées.

La version statique de cette interface sert donc de base frontend et doit être reliée à un backend d'authentification avant de publier du contenu réellement privé.
